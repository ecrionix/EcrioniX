9. Silicon Engineering Curriculum: 10 Architectural Lessons

Master deep learning hardware design from mathematical formulation down to physical silicon implementation. Click any lesson to expand.

Comprehensive Curriculum
Lesson 01 · Neural Networks to Digital Logic: High-Level Architecture ▼

Standard software neural networks rely on deep floating-point matrix multiplications ($O(N^3)$ or $O(N^2)$ GEMM) executed across thousands of GPU cores. In dedicated ASIC/FPGA hardware accelerators, our primary design objective is to eliminate floating-point execution units (which consume excessive silicon area and power) and structure the datapath around highly optimized fixed-point arithmetic units.

Our Mini AI Accelerator implements a 2-layer Multilayer Perceptron (MLP) with a 784 → 32 → 10 topology:

  • Input Dimension: 784 features, corresponding to a 28×28 grayscale pixel array.
  • Hidden Layer: 32 neurons with Rectified Linear Unit (ReLU) activation.
  • Output Layer: 10 neurons corresponding to numerical digits 0 through 9, followed by an Argmax peak selector.
  • Total MAC Operations: $(784 \times 32) + (32 \times 10) = 25,088 + 320 = 25,408$ multiply-accumulate steps.
Lesson 02 · Fixed-Point Quantization: INT8 Weights, UINT8 Inputs & INT32 Accumulators ▼

Floating-point 32-bit (FP32) multipliers require approximately 4,000–8,000 logic gates and introduce complex exponent alignment logic. By contrast, an 8-bit integer (INT8) multiplier consumes roughly 200–400 gates—a 20× area reduction and 15× energy savings.

In our accelerator:

  • Inputs ($X$): Unsigned 8-bit integers (`UINT8`), range $[0, 255]$. Zero corresponds to pure background, and 255 represents peak stroke intensity.
  • Weights ($W$): Signed 8-bit integers (`INT8`), two's complement range $[-128, +127]$. This allows both excitatory (positive) and inhibitory (negative) synaptic connections.
  • Biases ($B$): Signed 32-bit integers (`INT32`). Pre-scaled to match the accumulation scale, preventing truncation error before addition.
  • Accumulator ($Acc$): Signed 32-bit register (`INT32`). The worst-case accumulation across 784 products is $784 \times 255 \times 127 = 25,390,080$, which easily fits in a 25-bit signed integer without any danger of overflow in our 32-bit register.
Lesson 03 · Memory Architecture: Dual-Port BRAMs and Packed 32-bit ROMs ▼

In deep learning accelerators, memory bandwidth is the primary bottleneck ("The Memory Wall"). Storing parameters in external DRAM requires ~100–200 picojoules per read, whereas reading from on-chip SRAM/BRAM consumes less than 5 picojoules.

Our microarchitecture stores all parameters on-chip:

  • Input Buffer (`input_buffer.v`): 784-byte true dual-port RAM. Port A allows asynchronous burst writes from an external host/DMA interface. Port B provides single-cycle synchronous reads directly to the MAC unit.
  • Weight ROM (`weight_memory.v`): 25,408 bytes of signed INT8 weights. To prevent synthesizer lexer buffer overflows and maximize FPGA BRAM efficiency, weights are packed into 6,272 32-bit words (`w1_rom[0] = 32'h00000000;`). Byte selection logic extracts the target byte in combinational logic: assign w1_dout = (w1_word >> (w1_byte_sel * 8)) & 8'hFF;
  • Hidden Buffer (`hidden_buffer.v`): 32-byte dual-port distributed RAM holding intermediate activations between Layer 1 and Layer 2.
Lesson 04 · High-Performance MAC Unit Design: Multipliers and Accumulators ▼

The Multiply-Accumulate (`mac_unit.v`) block is the computational core of any NPU or tensor accelerator. Mathematically, it evaluates:

Acc[t+1] = (clear ? bias_in : Acc[t]) + (in_a × weight_b)

Crucial digital design considerations:

  • Signed Arithmetic Extension: `in_a` is an unsigned 8-bit value $[0..255]$, while `weight_b` is a signed 8-bit value $[-128..+127]$. To prevent unintended sign inversion during two's complement multiplication, `in_a` is zero-extended to a 9-bit signed integer (`{1'b0, in_a}`) before being multiplied with `weight_b`.
  • Single DSP Mapping: The 9-bit × 8-bit multiplication produces a 17-bit signed product. Modern FPGA DSP slices (e.g. Xilinx DSP48E1 with 25×18 multipliers) easily map this operation into a single primitive running up to 450 MHz.
Lesson 05 · Nonlinearity in Silicon: Zero-Cost Hardware ReLU & Arithmetic Shift ▼

Activation functions introduce non-linearity, enabling neural networks to learn complex boundary manifolds. While Sigmoid ($1/(1+e^{-x})$) and GELU require lookup tables (LUTs) or Taylor expansion hardware, the Rectified Linear Unit (ReLU) is virtually free in digital hardware:

ReLU(x) = max(0, x) = (din[31] == 1'b1) ? 0 : din

In `relu_unit.v`, evaluating the sign bit (`din[31]`) determines whether the accumulator is positive or negative. For positive values, we apply an arithmetic right shift by 10 (`>>> 10`, division by 1024) to scale the 32-bit accumulator back into an 8-bit activation. Values exceeding 255 are saturated to 255.

Lesson 06 · The AI Controller FSM: 12-State Hardware Orchestration ▼

The master finite state machine (`ai_controller.v`) controls the flow of addresses, read enables, accumulator clears, and activation latches over 25,495 clock cycles:

  • IDLE (0): Awaiting `start` trigger pulse.
  • LOAD_INPUT (1): Input pixels written to dual-port RAM.
  • INIT_HIDDEN (2): Pre-loads bias `b1[j]` into accumulator.
  • PIPE_HIDDEN (3): Primes the memory pipeline for pixel 0 and weight 0.
  • HIDDEN_MAC (4): Accumulates 784 MAC operations per hidden neuron.
  • HIDDEN_ACT (5): Executes ReLU + shift and stores activation in hidden RAM. Loops through all 32 neurons.
  • INIT_OUTPUT (6) & PIPE_OUTPUT (7): Pre-loads bias `b2[k]` and primes Layer 2 pipeline.
  • OUTPUT_MAC (8) & OUTPUT_STORE (9): Accumulates 32 hidden activations × output weights for 10 classes.
  • ARGMAX (10): Latches the winning class index and peak score.
  • DONE (11): Asserts `done` high, signaling completion to host system.
Lesson 07 · Argmax Hardware: Comparator Trees vs Serial Scanning ▼

The classification decision requires finding the index with the maximum output score: $\arg\max_k (S_k)$. Two primary hardware implementations exist:

  • Parallel Comparator Tree: Compares all 10 output scores simultaneously using a binary tree of 9 32-bit comparators. Latency is $\lceil \log_2(10) \rceil = 4$ clock cycles, but requires 9 comparator units in parallel.
  • Iterative Serial Peak Tracking (`argmax_unit.v`): As each output class score $S_k$ is calculated sequentially by the MAC unit, it is compared against a running maximum register: if (score_in > max_score_reg) begin max_score_reg <= score_in; pred_digit_reg <= class_idx; end This consumes only a single 32-bit comparator and costs zero additional latency, as comparison occurs concurrently with the output store state!
Lesson 08 · Testbench Architecture & Self-Checking Verification ▼

A digital hardware design is incomplete without rigorous verification. Our testbench (`tb_mini_ai_accelerator.v`) implements self-checking assertion logic:

  • Automated Clock & Reset Generator: Generates a symmetric 100 MHz clock (`always #5 clk = ~clk;`) and an active-low synchronous reset pulse.
  • Memory Preloading: Injects test images directly via Port A memory writes or `$readmemh`.
  • Timeout Watchdog: Terminates simulation with an error if the accelerator fails to assert `done` within 30,000 clock cycles.
  • Self-Checking Assertions: Verifies that the hardware RTL prediction matches the golden software reference model bit-for-bit.
  • Waveform Dumping: Generates IEEE 1364 Value Change Dump files (`$dumpfile("sim_dump.vcd"); $dumpvars(0, tb_mini_ai_accelerator);`).

Lesson 10 · Physical Silicon Deployment: From Simulation to OpenROAD & Tapeout ▼

How does this Verilog code turn into physical silicon? The OpenROAD RTL-to-GDSII physical design flow executes these discrete stages:

  1. Logic Synthesis (Yosys): Translates `mini_ai_accelerator_top.v` into technology-mapped logic gates (NAND, NOR, D-Flip-Flops) from the SkyWater 130nm library.
  2. Floorplanning: Defines chip core boundaries, power ring distribution (VDD/VSS rails), and macro placement for the input SRAM.
  3. Placement: Places standard cells across standard cell rows while minimizing total wire length.
  4. Clock Tree Synthesis (CTS): Synthesizes a balanced buffer tree to distribute the 100 MHz clock with minimal skew (<50 ps).
  5. Global & Detailed Routing: Connects cell pins using metal layers (Met1 through Met5) while avoiding design rule violations (DRC).
  6. GDSII Streaming & Tapeout: Generates the final binary mask file ready for fabrication foundry submission (e.g., Efabless ChipIgnite shuttle)!
