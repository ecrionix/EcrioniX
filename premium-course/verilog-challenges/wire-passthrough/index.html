Wire the Input Straight to the Output

Category 1 · Verilog Language Basics · Problem 1

Create a module named top_module with one input in and one output out that simply copies the input value to the output at all times — a plain wire.

Port list (must match exactly): 
module top_module(
  input   in,
  output  out
);
Concept: continuous assignment. In Verilog, assign out = in; wires out to in permanently — it's not a one-time copy, it's a standing connection that updates instantly whenever in changes, just like a real wire. This is the simplest possible piece of combinational logic, and almost every module you'll ever write builds on this same assign statement.
