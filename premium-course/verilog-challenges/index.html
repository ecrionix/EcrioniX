Verilog Coding Challenges

HDLBits-style problem sets, graded against hidden testbenches using the existing online Verilog simulator backend. Nothing here is public yet.

Plan

  • Reuse the /run Icarus Verilog backend (already live on the simulator) — submit the student's module alongside a hidden testbench, parse a pass/fail marker from the output.
  • Each problem: a short spec, a starter module stub, and a hidden testbench the student never sees.
  • Start small — a handful of problems tied to CDC lessons already built, before expanding further.
  • Watch backend load: the simulator's HF Space sleeps on inactivity and has wake-up retry logic already; more frequent submissions here may need a queue or cooldown.
