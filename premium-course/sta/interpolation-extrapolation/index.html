Lesson 6.8

Interpolation and Extrapolation in LUTs

What happens when the actual slew and load values in a design don't exactly match the data points in the `.lib` LUT? The STA tool uses Interpolation and Extrapolation.

1

Interpolation (Within the Box)

If the actual slew and load fall between the characterized points in the 2D table, the STA engine performs 2D bilinear interpolation. This is generally highly accurate since the characterized grid is dense enough to approximate the non-linear curve locally.

2

Extrapolation (Outside the Box)

If a gate drives an unusually large load (or sees an extremely slow input slew) that exceeds the maximum values in the LUT, the tool must extrapolate.

The Danger of Extrapolation: Extrapolating non-linear data is inherently risky. The tool assumes a linear trend beyond the last known data point, which is often false for transistors. This causes severe timing inaccuracies. Designers must fix "Max Capacitance" or "Max Transition" DRCs to ensure the tool operates strictly within the interpolated region.
