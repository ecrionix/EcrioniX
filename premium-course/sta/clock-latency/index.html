Lesson 4.4

Clock Latency (Source vs. Network)

Total clock insertion delay has two distinct components: source latency and network latency.

1

Source Latency

Source latency is the delay from the actual clock origin (like an off-chip oscillator or on-chip PLL) to the clock definition point (the port or pin where the clock is defined in STA).

Use set_clock_latency -source <delay> [get_clocks clk] to model this delay. This is critical when interfacing with external components where the off-chip clock arrival time matters.

2

Network Latency

Network latency is the delay from the clock definition point (e.g., the top-level port) to the clock pin of the flip-flops.

Post-CTS Reality

Before CTS, network latency is an estimate provided via set_clock_latency. After CTS, it is computed accurately from the RC extraction of the clock tree (propagated clock).
