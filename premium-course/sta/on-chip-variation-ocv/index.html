STA / Module 7: Operating Conditions (PVT)
Lesson 7.5

On-Chip Variation (OCV)

Global corners (SS, FF) assume the entire chip is operating identically. In reality, local variations across the die cause On-Chip Variation (OCV), meaning two identical cells side-by-side can have different delays.

1

The Global vs. Local Problem

If you run STA at the SS corner, every gate is slow. However, for a setup check, the worst case isn't just "everything is slow." The absolute worst case is when the launch data path is exceptionally slow, but the capture clock path is exceptionally fast.

OCV models this pessimism. It assumes that variations in voltage drop (IR drop), local hotspots (Temperature), and micro-manufacturing defects (Process) cause localized mismatches.

2

How OCV Works in STA

To model OCV, STA tools apply Derating Factors (e.g., +/- 10%) to path delays.

  • For Setup Checks: Derate the launch path (data + launch clock) to be SLOWER (e.g., x 1.1). Derate the capture clock path to be FASTER (e.g., x 0.9).
  • For Hold Checks: Derate the launch path to be FASTER (e.g., x 0.9). Derate the capture clock path to be SLOWER (e.g., x 1.1).
The Catch-Up Game

Imagine a race where Runner A (Data) tries to reach a checkpoint before Runner B (Capture Clock). OCV puts weights on Runner A's ankles and gives Runner B a tailwind, making the timing requirement exceptionally hard to meet. If your design passes OCV, it is robust.

3

Common Path Pessimism Removal (CPPR)

There's a flaw in simple OCV: the launch clock and capture clock often share the same source tree before branching off. OCV derates the shared portion differently for launch and capture, which is physically impossible (a single wire cannot be simultaneously fast and slow).

CRPR / CPPR

Clock Reconvergence Pessimism Removal (CRPR) analyzes the common clock path and removes the artificial OCV penalty added to it. STA tools do this automatically.

🎯 Key Takeaway

  • OCV models local PVT differences across a single die.
  • It intentionally worsens setup and hold checks by misaligning launch and capture delays.
  • CPPR is required to remove physically impossible pessimism on shared clock paths.
