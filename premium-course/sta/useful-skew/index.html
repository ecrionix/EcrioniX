Lesson 9.8

Useful Skew (Clock Scheduling)

When we can no longer speed up the data path, we alter reality by delaying the clock edge. This powerful technique is called Useful Skew.

1

Time Borrowing

Setup margin is calculated as: Capture Clock Edge Time - Data Arrival Time. If Data Arrival is too large, you fail setup.

The Skew Trick

Instead of making the data faster, we intentionally delay the capture clock edge by adding buffers in the clock tree branch going to the capture flop. This pushes the setup requirement later in time, rescuing the violation.

The Trade-off: By delaying the clock at the capture flop, you steal time from the NEXT path. The capture flop now launches its data later, making it harder for the downstream logic to meet setup. You can only use Useful Skew if the subsequent path has positive slack to spare.
