STA / Module 2: STA Concepts & Terminology
Lesson 2.10

The Data Required Time (DRT)

Once the STA tool knows when the data actually arrives (DAT), it needs to know when the data was required to arrive. This limit is called the Data Required Time (DRT).

1

The Equation for DRT (Setup Check)

The DRT for a setup check calculates the latest possible time the data can arrive and still be safely captured.

Setup DRT Formula

DRT = Capture_Edge_Time + Capture_Clock_Path_Delay - Setup_Requirement - Uncertainty

2

Breaking Down the Components

  • Capture Edge Time: For a single-cycle setup check, this is typically 1 Clock Period (e.g., 10ns).
  • Capture Clock Path Delay: The time it takes for the clock pulse to travel down the clock tree to the Capture Flip-Flop. (This helps DRT by pushing the capture edge later).
  • Setup Requirement: The physical setup time required by the destination flip-flop (found in the .lib). We must subtract this because the data must arrive before the edge.
  • Uncertainty: A margin (jitter, margin) subtracted to make the check more pessimistic.
3

The Ultimate Goal: Slack

The ultimate goal of STA is to compute Slack.

Slack Equation
Slack = Data Required Time (DRT) - Data Arrival Time (DAT)

If Slack is positive, your design meets timing! If Slack is negative, your data arrived too late, and the chip will fail. This brings Module 2 to a close.

🎯 What to remember

  • DRT defines the deadline for the data.
  • Slack = DRT - DAT.
  • Positive slack is a pass. Negative slack is a violation.
