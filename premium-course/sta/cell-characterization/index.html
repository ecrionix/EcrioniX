Lesson 6.7

Cell Characterization (.lib files)

Where do STA models come from? They are generated through rigorous Cell Characterization by library teams using tools like SiliconSmart.

1

The Characterization Flow

Standard cells (AND, OR, DFF, etc.) are designed at the transistor level. To use them in synthesis and STA, they must be abstracted into a `.lib` file. This is done by running thousands of automated SPICE simulations.

  • Vary input slew (e.g., 7 points).
  • Vary output load capacitance (e.g., 7 points).
  • Measure the propagation delay and output transition time.
  • Record the values into NLDM, CCS, or ECSM tables.
2

Liberty (.lib) Format

The output of characterization is the Liberty file. It contains timing, power, and noise tables for every cell in the library under specific PVT (Process, Voltage, Temperature) corners.

A single `.lib` file represents ONE specific corner (e.g., `tt_1v0_25c.lib`). You need multiple `.lib` files to perform Multi-Mode Multi-Corner (MMMC) STA.
