Lesson 5.9

Data to Data Checks

Most STA checks data against a clock. But sometimes, you need to check the relative arrival times of two data signals.

1

Why Check Data against Data?

Certain logic structures, such as multiplexers, clock gates, or custom asynchronous logic, require one data signal to be stable before another signal arrives.

For example, in a clock gating cell (ICG), the enable signal must be stable before the clock pulse arrives. This is technically a data-to-clock check, but similar custom checks can be defined via set_data_check.

2

How It Works

You manually specify that Signal A must arrive at least X picoseconds before Signal B.

SDC Command
set_data_check -setup 200 -from A -to B
set_data_check -hold 100 -from A -to B

STA then treats Signal B as the "clock" and Signal A as the "data", running standard setup and hold math on them.

🎯 What to remember

  • Data-to-data checks are custom constraints defined in SDC.
  • They enforce relative timing between two non-clock signals.
