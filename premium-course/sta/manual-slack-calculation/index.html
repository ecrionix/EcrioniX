Lesson 5.10

Practice: Manual Slack Calculation Problems

You've learned the theory. Now it's time to crunch the numbers like a real timing sign-off engineer.

1

Problem 1: Setup Slack

Given the following parameters, calculate the setup slack:

  • Clock Period = 10ns
  • Launch Clock Path Delay = 1.2ns
  • Capture Clock Path Delay = 1.5ns
  • Clock-to-Q Delay = 0.5ns
  • Combinatorial Data Path Delay = 8.0ns
  • Setup Time of Capture Flop = 0.4ns

Solution:
Data Arrival Time = 1.2 + 0.5 + 8.0 = 9.7ns
Data Required Time = 10.0 + 1.5 - 0.4 = 11.1ns
Setup Slack = 11.1 - 9.7 = +1.4ns (Meets timing)

2

Problem 2: Hold Slack with CPPR

Given the following parameters, calculate the hold slack:

  • Launch Clock Path Delay = 2.0ns
  • Capture Clock Path Delay = 2.2ns
  • Clock-to-Q Delay = 0.3ns
  • Combinatorial Data Path Delay = 0.1ns
  • Hold Time of Capture Flop = 0.2ns
  • CPPR Credit = 0.15ns

Solution:
Data Arrival Time = 2.0 + 0.3 + 0.1 = 2.4ns
Data Required Time = 2.2 + 0.2 = 2.4ns
Hold Slack (without CPPR) = 2.4 - 2.4 = 0ns
Hold Slack (with CPPR) = 0 + 0.15 = +0.15ns (Meets timing safely!)

🎯 What to remember

  • Always write out DAT and DRT separately before subtracting.
  • Don't forget CPPR can save a failing path!
