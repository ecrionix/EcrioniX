Lesson 7.2

Slow-Slow (SS) Corner

The Slow-Slow (SS) corner is the worst-case scenario for maximum delays. It is where your setup timing margins are put to the ultimate test.

1

Defining the SS Corner

The "SS" nomenclature specifically refers to the Process (P) condition: Slow NMOS and Slow PMOS. In a CMOS library, both the pull-up network (PMOS) and pull-down network (NMOS) exhibit maximum delay in this corner.

Worst-Case Environment

To find the absolute maximum delay, we combine the SS Process with the worst V and T:
PVT: SS / Vmin / Tmax (usually)
Low voltage provides the least drive current, and high temperature degrades mobility (in older nodes), creating the longest possible path delay.

2

Impact on Setup Timing

Setup time violations occur when data arrives too late at the capturing flip-flop. The SS corner maximizes the delay of the combinational logic and the launch clock path.

setup_equation.txt
Setup Slack = Clock Period + Clock Skew - Data Path Delay - Setup Time Margin
      
At SS Corner:
- Data Path Delay is MAXIMIZED (bad for slack).
- Setup slack shrinks and may go negative.

Because SS evaluates maximum delays, it is almost exclusively used for checking Setup (Max) timing.

3

WaveDrom Timing Visualization

Notice how in the SS corner, the propagation delay (Tpd) stretches out, eating into the setup margin before the next clock edge.

🎯 Key Takeaway

  • SS (Slow-Slow) means weak NMOS and weak PMOS.
  • Paired with Vmin and Tworst (often Tmax), it gives the longest delay.
  • SS corner is the gold standard for verifying Setup Timing.
  • Next up: The opposite extreme, the Fast-Fast (FF) corner.
