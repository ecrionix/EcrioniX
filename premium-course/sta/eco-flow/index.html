Engineering Change Orders (ECO) Flow

When the chip is almost ready to tape-out, running the full synthesis and PnR flow from scratch takes too long. We make surgical edits using ECOs.

1

What is an ECO?

An Engineering Change Order is a direct, manual or semi-automated modification to the netlist or layout, bypassing the main compilation tools. We patch the database directly.

The ECO Philosophy

Do as little damage as possible. Only fix what is explicitly broken. Do not disrupt the placement or routing of surrounding, passing logic.

2

Typical ECO Sequence

🔍

1. Analysis

Extract STA timing reports. Identify root cause of failure (slew, load, logic depth).

📝

2. Scripting

Write Tcl scripts with direct commands (size_cell, insert_buffer) to apply the fix.

🏗️

3. Implementation

Load script into the PnR tool. The tool performs a localized placement and routing update.

✅

4. Verification

Re-extract delays and re-run STA. Ensure no new violations were created.
