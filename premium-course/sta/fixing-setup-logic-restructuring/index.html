Lesson 9.3

Fixing Setup: Logic Restructuring

When sizing cells isn't enough, we must physically alter the logic equations. Logic restructuring rewires the combinatorial cloud to flatten critical paths.

1

Late Arriving Signals

Often, a deep combinatorial tree has one input that arrives much later than the others. If this late signal has to pass through 5 layers of logic, it will invariably cause a setup violation.

The Restructuring Fix

We restructure the logic tree to move the late-arriving signal closer to the output (the destination flop). By bypassing several logic stages, the late signal experiences less delay, meeting the setup requirement.

2

De-Morgan's Laws and Flattening

Synthesis tools aggressively restructure logic using boolean algebra. Converting deeply cascaded AND/OR gates into wider, flatter NAND/NOR structures can reduce the total number of gate delays.

Example: `A AND B AND C AND D` might be implemented as a chain: `(((A AND B) AND C) AND D)`. If A arrives late, this is terrible. Restructuring to a parallel tree `(A AND B) AND (C AND D)` flattens the delay from 3 gate depths to 2 gate depths.
