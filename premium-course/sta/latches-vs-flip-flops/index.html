Latches vs. Flip-Flops

Sequential logic stores state. But the when and how of that storage heavily dictate our timing constraints.

1

Level-Sensitive vs. Edge-Triggered

A latch is transparent when the clock is high (or low). A flip-flop only captures data exactly on the rising (or falling) edge.

Fundamental Difference

Latches are level-sensitive (time borrowing is possible). Flip-flops are edge-triggered (rigid cycle boundaries).

2

Timing Diagram

Notice how the latch output changes as soon as D changes (while clk is high), whereas the flop strictly waits for the positive edge.

STA Rule: Flip-flops create strict boundaries for setup and hold timing. Latches allow "time borrowing" which complicates STA significantly.
