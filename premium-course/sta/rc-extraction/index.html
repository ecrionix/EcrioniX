Lesson 6.5

RC Extraction (SPEF)

Once a chip is placed and routed, we no longer need to guess wire lengths. We perform RC Extraction and write the results to a SPEF file.

1

Standard Parasitic Exchange Format (SPEF)

SPEF is the IEEE standard format for representing parasitic resistance (R) and capacitance (C) of interconnects in an IC design.

Parasitics

Unwanted, but unavoidable physical properties. Wires have resistance based on their metal layer (width, thickness). Wires have capacitance to the substrate and to neighboring wires (coupling).

2

Anatomy of a SPEF File

A SPEF file details the exact R and C network for every net in the design. It represents wires as distributed RC Pi-networks.

SPEF Snippet Example
*D_NET n_clk 0.520
*CONN
*P clk I
*I u_ff1:CK I
*I u_ff2:CK I
*CAP
1 n_clk:1 0.05
2 n_clk:2 0.08
3 n_clk:1 n_data:2 0.12  // Coupling capacitance to another net!
*RES
1 n_clk:1 n_clk:2 0.35

Notice the coupling capacitance explicitly mentioned. This is what modern STA tools use to accurately calculate crosstalk and Miller delay.

3

Extraction Tools

Tools like StarRC (Synopsys) or Quantus (Cadence) read the physical layout (GDSII or LEF/DEF) and the technology physical rules (RC models from the foundry) to generate the SPEF. This SPEF is then loaded into PrimeTime for signoff STA.
