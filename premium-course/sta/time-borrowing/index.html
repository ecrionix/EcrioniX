Lesson 5.6

Time Borrowing (Latch-based designs)

Flip-flops are strict—they capture data exactly on the edge. Latches are flexible—they let data flow through while they are open. This flexibility allows for time borrowing.

1

Level-Sensitive vs Edge-Triggered

A latch is transparent during its active phase (e.g., when Clock is High). If data arrives early, it passes through immediately. But if data arrives late—after the rising edge but before the falling edge—it still passes through and is captured successfully on the falling edge.

2

Borrowing Time

When a latch allows late data to be captured, it is effectively borrowing time from the next timing path.

Time Borrowing Principle

A slow path ending at a latch can "borrow" time from the subsequent path, provided the subsequent path is fast enough to give up that time without violating its own setup constraints.

Data arriving after the rising edge is still captured because the latch is open.

🎯 What to remember

  • Latches permit time borrowing, smoothing out unbalanced logic delays.
  • Time borrowed by Path 1 must be subtracted from the available time for Path 2.
  • Latch-based STA is significantly more complex than flop-based STA.
