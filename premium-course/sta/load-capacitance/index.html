STA / Module 2: STA Concepts & Terminology
Lesson 2.6

Load Capacitance

Every time a cell tries to drive a signal, it must charge up the Load Capacitance of the net. A higher capacitance makes it harder for the cell to toggle the signal quickly.

1

Components of Load Capacitance

The total capacitance seen by an output pin is the sum of two things:

  • Pin Capacitance (Gate Cap): The input capacitance of all the receiver cells connected to the net.
  • Wire Capacitance (Parasitic Cap): The capacitance of the metal wire itself routing across the chip.
2

The Table Lookup Model

How does the STA tool calculate cell delay? It uses a 2D lookup table defined in the .lib file.

Cell Delay Function
Cell_Delay = function (Input_Slew, Output_Load)

As Output Load increases, the cell delay increases (it takes longer to charge a larger capacitor) and the output slew becomes worse (slower).

⚠ Max Capacitance

STA tools enforce a max_capacitance limit. If a cell is driving too many receivers (high fanout) or a very long wire, it will violate this rule. The fix is to insert a buffer tree.

🎯 What to remember

  • Load Capacitance = Wire Cap + sum(Pin Caps).
  • More capacitance = more delay and slower slew.
  • Cell delay is fundamentally a lookup table based on Input Slew and Output Load Capacitance.
