STA / Module 8: Timing Exceptions
Lesson 8.3

Logical vs. Physical False Paths

Not all false paths are created equal. We must differentiate between a path that is false due to physics and one that is false due to boolean logic.

1

Physical False Paths

These are paths between two asynchronous clocks. They are physically incapable of being timed reliably because the clock phase relationship is entirely random. We declare these as false paths and rely on synchronizers (like 2-stage flip-flops) to resolve metastability.

2

Logical False Paths

These occur within a single clock domain. Structurally, a timing arc exists from flop A to flop B. However, the boolean logic in the combinational cloud makes it impossible for a signal transition at A to ever propagate and cause a change at B.

For example, imagine a multiplexer tree where the select signals are mutually exclusive, but the structural paths cross over. The STA engine is purely structural—it traces paths regardless of whether they make logical sense. Thus, it might report a violation on a path that can never logically flip. We mask this out by setting a false path on the logically impossible arc.
