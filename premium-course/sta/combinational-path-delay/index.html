Introduction to Combinational Delay

In digital design, a combinational logic path consists of a sequence of logic gates and the wires interconnecting them. There are no memory elements (flip-flops, latches, or RAMs) within a purely combinational path. The total delay through this path is the sum of the delays contributed by the logic cells (gates) and the connecting networks (wires).

Understanding combinational path delay is foundational to Static Timing Analysis (STA). It determines how fast a signal can propagate from a set of inputs to a set of outputs, fundamentally dictating the maximum operating frequency of a synchronous design.

Cell Delay vs. Net Delay

The total propagation delay along a path, $T_{pd}$, is composed of two primary components: Cell Delay and Net Delay.

Cell Delay (Gate Delay)

Cell delay represents the time it takes for a signal to transition from the input pin of a logic gate to its output pin. It is fundamentally determined by the time required to charge or discharge the parasitic capacitances within the transistors forming the gate.

In standard cell libraries used for ASIC synthesis, cell delay is pre-characterized and stored in timing libraries (such as .lib files). It is typically represented as a two-dimensional non-linear delay model (NLDM) look-up table dependent on two factors:

  1. Input Transition Time (Slew): How fast the input signal is changing. A slower, degraded input transition results in a larger cell delay because the transistors take longer to fully turn on or off.
  2. Output Load Capacitance: The total capacitance the gate must drive. This includes the pin capacitances of all driven gates and the parasitic capacitance of the interconnecting wires.

Net Delay (Wire Delay)

Net delay is the time it takes for a signal to travel along the interconnecting wires from the output pin of a driving cell to the input pin of a receiving cell. In deep sub-micron (DSM) and FinFET technology nodes, net delay often dominates the total path delay.

Net delay is primarily calculated using the parasitic Resistance (R) and Capacitance (C) of the routing metal. STA tools extract these RC values (often represented in SPEF format) and compute the delay using models like Elmore delay or more advanced model-order reduction techniques like AWE (Asymptotic Waveform Evaluation).

Total Path Delay = Σ (Cell Delays) + Σ (Net Delays)
The Concept of the Critical Path

In any design, there are numerous combinational paths operating in parallel between pairs of sequential elements (or primary inputs/outputs). The Critical Path is defined as the path with the longest total propagation delay in the entire design (or within a specific clock domain).

Why is it critical? Because the critical path limits the overall performance of the circuit. In a synchronous system, the clock period cannot be shorter than the delay of the critical path (plus flip-flop setup time and clock skew). If the clock ticks faster than the critical path can evaluate, the receiving flip-flop will sample incorrect data, leading to a functional failure.

STA tools focus heavily on identifying the top critical paths so that designers can optimize them by resizing cells, reducing wire lengths, or changing the logic structure.

Max Delay Path vs. Min Delay Path

When analyzing timing, we must consider variation in operating conditions (Process, Voltage, and Temperature, or PVT). Furthermore, logic gates can exhibit different delays for rising and falling transitions.

Max Delay Path

The Max Delay Path (often referred to as the Late Path) is the path that takes the longest possible time to propagate a signal. STA calculates this using the worst-case PVT corner (typically slow process, low voltage, high temperature) to ensure that the data arrives in time for the Setup Check.

Min Delay Path

The Min Delay Path (often referred to as the Early Path) is the path that propagates a signal in the shortest possible time. STA calculates this using the best-case PVT corner (fast process, high voltage, low temperature). This is crucial for verifying the Hold Check, ensuring that data doesn't race through the combinational logic so fast that it overwrites the previous data before the flip-flop can capture it.

A robust design must satisfy timing constraints for both the absolute maximum (setup) and absolute minimum (hold) delay paths across all operating corners.

How Fan-out Affects Cell Delay (Load Capacitance)

Fan-out refers to the number of input pins (loads) that a single output pin drives. There is a direct, critical relationship between fan-out and cell delay.

As fan-out increases, the driving cell must charge and discharge the input capacitance of every connected receiving cell, plus the capacitance of the extended wire network connecting them. This cumulative Load Capacitance ($C_{load}$) directly dictates the output transition time.

  • Increased Load = Slower Output Slew: A higher $C_{load}$ means the driving transistor takes longer to pull the output voltage up to $V_{DD}$ or down to Ground.
  • Slower Output Slew = Increased Cell Delay: As the output transition slows down, the overall delay of that specific cell increases.
  • Domino Effect: Furthermore, a slow output slew from the driving cell becomes a slow input slew for the receiving cells. As we learned earlier, a slower input slew increases the delay of the receiving cells as well!

Diagram: As fan-out increases, the slew rate degrades and the propagation delay shifts outward. High fan-out nets often require buffer trees to isolate load capacitance and restore signal transition times.

Notice how the tool alternates between calculating the delay through the cell (e.g., AND2_X2 takes 0.22ns) and the delay across the net connecting it to the next cell (e.g., wire to INV_X1 takes 0.05ns).
