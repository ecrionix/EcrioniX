STA / Module 9: Fixing Violations
Lesson 9.7

The "Hold Fixing creates Setup Violation" Trap

Welcome to the most frustrating cycle in STA ECOs: the infinite loop where fixing a hold violation causes a setup violation, and fixing that setup violation creates a hold violation.

1

The Ping-Pong Effect

Setup checks and hold checks are fundamentally opposed. Setup wants the data path to be as fast as possible. Hold wants the data path to be slow.

The Window of Validity

If you insert a buffer to fix a hold violation (slowing the path down), you might push the data arrival time past the required setup time of the next clock cycle. This usually happens when the slack margin between setup and hold is extremely tight, or you are running at very high frequencies.

2

How to Break the Loop

If you cannot simply size cells up or down without violating the other check, you must use structural fixes:

  • Useful Skew: Borrow time by shifting the clock arrival time at the launch or capture flop.
  • VT Swapping: Swap the threshold voltages of the cells instead of their physical drive strength sizes to achieve more granular delay changes.
