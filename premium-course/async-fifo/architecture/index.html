Lesson 4.1

Dual-clock architecture

An async FIFO is two pointer engines plus a dual-port RAM. Data never crosses. Gray pointers cross through 2FF synchronizers. Full lives with the writer. Empty lives with the reader.

1

Block diagram

Dual-port RAM sits on the boundary: write-side sequential, read-side sequential, no combinational path between clocks.

2

What crosses the CDC

Because a 2FF chain delays the pointer by two destination clocks, flags are slightly pessimistic: you may see full a little early and empty a little early. That can cost a few entries of apparent depth. It must never allow overflow/underflow.

3

Power-of-two depth

Gray pointer wrap only stays unit-distance for a binary count that uses all 2^n states. Classic async FIFO depth must be a power of two. For a 10-deep FIFO you either waste 6 locations (use 16) or use a different (harder) style: dual n-bit Gray plus converted occupancy, or a vendor hard FIFO.

Key takeaways

  • Two domains, two pointers, one dual-port RAM.
  • Only Gray pointers cross, each through a 2FF.
  • Flags are conservative because of synchronizer latency.
