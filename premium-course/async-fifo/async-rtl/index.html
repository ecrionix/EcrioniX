Lesson 4.3

Complete async FIFO RTL

One module, two clocks, dual-port RAM, registered Gray pointers, combinational full/empty from next Gray. This is the block you should be able to reconstruct in an interview.

1

Synthesizable listing

async_fifo.v
module async_fifo #(
  parameter WIDTH  = 8,
  parameter DEPTH  = 16,                 // MUST be power of 2
  parameter ADDR_W = $clog2(DEPTH)
)(
  input  wire             wr_clk,
  input  wire             wr_rst_n,
  input  wire             wr_en,
  input  wire [WIDTH-1:0] wdata,
  output wire             full,
  input  wire             rd_clk,
  input  wire             rd_rst_n,
  input  wire             rd_en,
  output reg  [WIDTH-1:0] rdata,
  output wire             empty
);
  localparam PTR_W = ADDR_W + 1;

  reg [WIDTH-1:0] mem [0:DEPTH-1];

  // Pointers declared first so the 2FF can sample rgray / wgray.
  reg  [PTR_W-1:0] wbin, wgray, rbin, rgray;
  reg  [PTR_W-1:0] wq1_rgray, wq2_rgray;
  reg  [PTR_W-1:0] rq1_wgray, rq2_wgray;

  // Registered-pointer flags (no combinational loop). The beat that fills
  // the last slot is legal; full rises on the following wr_clk.
  assign full  = (wgray == {~wq2_rgray[PTR_W-1:PTR_W-2], wq2_rgray[PTR_W-3:0]});
  assign empty = (rgray == rq2_wgray);

  wire wr_fire = wr_en & ~full;
  wire rd_fire = rd_en & ~empty;

  wire [PTR_W-1:0] wbin_next  = wbin + wr_fire;
  wire [PTR_W-1:0] wgray_next = wbin_next ^ (wbin_next >> 1);
  wire [PTR_W-1:0] rbin_next  = rbin + rd_fire;
  wire [PTR_W-1:0] rgray_next = rbin_next ^ (rbin_next >> 1);

  // ---- write domain ----

  always @(posedge wr_clk or negedge wr_rst_n) begin
    if (!wr_rst_n) begin
      wbin  <= {PTR_W{1'b0}};
      wgray <= {PTR_W{1'b0}};
    end else begin
      wbin  <= wbin_next;
      wgray <= wgray_next;
    end
  end

  always @(posedge wr_clk)
    if (wr_fire) mem[wbin[ADDR_W-1:0]] <= wdata;

  always @(posedge wr_clk or negedge wr_rst_n) begin
    if (!wr_rst_n) {wq2_rgray, wq1_rgray} <= {{PTR_W{1'b0}},{PTR_W{1'b0}}};
    else           {wq2_rgray, wq1_rgray} <= {wq1_rgray, /* rgray from rd domain */ rgray};
  end

  always @(posedge rd_clk or negedge rd_rst_n) begin
    if (!rd_rst_n) begin
      rbin  <= {PTR_W{1'b0}};
      rgray <= {PTR_W{1'b0}};
    end else begin
      rbin  <= rbin_next;
      rgray <= rgray_next;
    end
  end

  always @(posedge rd_clk)
    if (rd_fire) rdata <= mem[rbin[ADDR_W-1:0]];

  always @(posedge rd_clk or negedge rd_rst_n) begin
    if (!rd_rst_n) {rq2_wgray, rq1_wgray} <= {{PTR_W{1'b0}},{PTR_W{1'b0}}};
    else           {rq2_wgray, rq1_wgray} <= {rq1_wgray, wgray};
  end
endmodule
DEPTH = 2

For PTR_W == 2 there are no [PTR_W-3:0] bits — full is just wgray == ~wq2_rgray (both bits inverted). The listing assumes DEPTH >= 4 (PTR_W >= 3), which is the usual teaching and product case.

Verilog cross-domain read of rgray / wgray

The listing reads rgray inside the write-domain 2FF and wgray inside the read-domain 2FF. Those source flops must be the registered Gray nets. The first stage of each 2FF is the metastability absorber. Do not add combo logic on that path. Some lint tools still flag the cross-module clock; the intent is a synchronizer — constrain it in SDC as a false path into FF1, or use a dedicated sync cell.

2

Line-by-line

  1. wr_fire / rd_fire never commit when the registered flag is already set.
  2. wgray_next is Gray of the next binary — converted before the flop, then registered.
  3. full / empty compare registered Gray (no combinational loop through the incrementer).
  4. RAM write address is current wbin (the location being filled this cycle).
  5. Read side is the mirror: empty from rgray vs 2FF-synced write Gray.

Key takeaways

  • Two incrementers, two Gray registers, two 2FF chains, one RAM.
  • full / empty from registered Gray vs 2FF-synced opposite Gray (two MSBs inverted for full).
  • DEPTH power of two. PTR_W = ADDR_W+1.
