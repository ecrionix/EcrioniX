Lesson 2.1

Ring buffer, extra MSB, full vs empty

When write and read pointers are equal, the FIFO is either empty or full. That ambiguity is the entire pointer design problem. Solve it on one clock first.

1

Circular memory

Address = low ADDR_W bits of the pointer. After the last location, the pointer wraps. Occupancy is the number of unread beats, not “how far the pointer is from 0”.

Occupied slots sit strictly between rd and wr in ring order.

2

Three correct full/empty methods

Wrong

empty = (wptr == rptr); full = (wptr == rptr); is always a bug. Equal pointers cannot mean both.

3

Extra-MSB worked example (DEPTH = 4)

ADDR_W = 2. Pointers are 3 bits. Address = ptr[1:0]. Wrap bit = ptr[2].

4 more writes (wrap)000 after 8 writes total vs 4 reads…track wrap bit

After four writes from reset: wptr=100, rptr=000. Addresses match (00), MSBs differ → full, occupancy = 4. After four reads: both 100 → equal including MSB → empty.

pointer_flags.v
// DEPTH power of two. PTR_W = ADDR_W + 1
wire empty = (wptr == rptr);
wire full  = (wptr == {~rptr[PTR_W-1], rptr[PTR_W-2:0]});
4

Simultaneous read+write

Count method: count holds. Pointer method: both pointers increment; difference stays the same. If empty, a same-cycle write+read is a design choice (FWFT vs standard): this course uses standard — you cannot read while empty, so rd_fire is 0 even if wr_en=1 on that cycle.

Key takeaways

  • Equal n-bit addresses are ambiguous. Add a wrap bit or a count.
  • Full: addresses equal, wrap bits differ. Empty: entire pointers equal.
  • Always gate: wr_fire = wr_en && !full, rd_fire = rd_en && !empty.
