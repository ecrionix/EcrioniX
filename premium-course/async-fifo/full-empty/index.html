Lesson 4.2

Full and empty flag formulas

Empty: Gray pointers equal in the read domain. Full: Gray pointers match after inverting the two MSBs of the synchronized read pointer in the write domain. That is the Cummings style used in production RTL.

1

Empty — read domain

The reader knows the exact read Gray pointer. It only has a delayed copy of the write Gray pointer (rq2_wgray). If they are equal, every write the reader has heard about has already been consumed → empty.

If a write just happened but has not yet come through the 2FF, the reader still sees empty. That is conservative: you wait extra rd_clk cycles, you do not underflow.

empty
assign empty = (rgray == rq2_wgray);

Using rgray_next (combinational empty) is an alternative that goes empty on the cycle you pop the last beat, but it creates a combinational loop through rd_fire. Lesson 4.3 uses registered compare — simpler to synthesize. Then rd_fire = rd_en && !empty still prevents underflow.

2

Full — write domain, invert two MSBs

Pointers are ADDR_W+1 bits. When the writer has wrapped one more time than the reader, addresses match and the extra wrap bit differs. In Gray code that condition is: synchronized read Gray equals write Gray with the upper two bits inverted (not only the single MSB — because Gray’s MSB pair encodes the wrap).

full
// PTR_W = ADDR_W + 1. Invert Gray[PTR_W-1] and Gray[PTR_W-2].
assign full = (wgray ==
  {~wq2_rgray[PTR_W-1:PTR_W-2], wq2_rgray[PTR_W-3:0]});

Worked DEPTH=4, PTR_W=3. After 4 writes, wgray is Gray(4)=110 (bin 100). rptr still 000 → Gray 000. Invert two MSBs of 000 → 110. 110 == 110 → full. Correct.

After 4 reads, rptr=100, rgray=110. Synced into write domain. Invert two MSBs of 110 = 000. wptr also wrapped or not depending on more writes — check equal-pointer empty on read side separately.

Do not invert only one bit

Binary extra-MSB full is {~rptr[MSB], rptr[rest]} (one bit). Gray full inverts two MSBs. Mixing the two formulas is a common whiteboard mistake.

3

Why two MSBs — short Gray reason

For an (n+1)-bit Gray code, going around the circle once flips the pattern of the top two bits in a way that a single-bit invert does not match the Gray of (binary + 2^n). The SNUG-2002 identity is: full when wgray == {~rgray[n:n-1], rgray[n-2:0]} using the synchronized rgray.

4

Waveform — conservative empty

Key takeaways

  • Empty in rd domain: registered read Gray equals 2FF-synced write Gray.
  • Full in wr domain: Gray equal after inverting two MSBs of synced rgray.
  • 2FF delay makes flags pessimistic, which is required for safety.
