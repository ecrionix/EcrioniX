UVM / verification career path

UVM is the industry standard for ASIC verification — but it's a different job from RTL design for many teams.

🎯

RTL designer

Directed TB + assertions often enough at junior level. Your I2C self-checking TB is credible.

🔬

DV engineer

UVM required at most ASIC houses. Learn after solid Verilog — 2–3 month investment.

⚡

FPGA engineer

Often directed TB + ILA. UVM less common unless ASIC prototyping flow.

5

Physical design — awareness, not mastery

RTL designers don't place and route — but they need to speak PD's language.

  • Floorplan impact: Pad-adjacent blocks (like I2C) vs core logic — affects wire delay
  • Clock tree: Your sys_clk becomes a distributed tree — skew matters for hold
  • Power: Clock gating decisions start in RTL
  • DFT: Scan chains affect how you write reset and pad logic

Read physical design lesson and signoff overview — enough to not embarrass yourself in a cross-team meeting. Don't try to become a PD engineer unless that's the role you want.

6

SystemVerilog / SVA — deepen

Industry RTL increasingly uses SystemVerilog. Your Verilog transfers — add these incrementally:

sva_example.sv — I2C START assertion
// Assert START condition: SDA falls while SCL is high
property p_i2c_start;
  @(posedge clk) disable iff (!rst_n)
    (scl === 1'b1) |-> ##[0:2] (sda === 1'b0);
endproperty
ap_start: assert property (p_i2c_start);
  • Learn logic vs wire/reg — mostly drop reg in SV
  • Interfaces for bus connections (APB, AXI later)
  • Assertions on FSM illegal states and protocol rules
  • typedef enum for state — you already saw this in 12.2
7

CDC — EcrioniX deep dive

Module 10 introduced CDC mindset. For ASIC roles, take the dedicated EcrioniX CDC course when available — it covers:

  • Gray-code async FIFO (full implementation)
  • Handshake protocols (req/ack)
  • CDC lint tools (SpyGlass, Jasper)
  • Real waiver documentation
  • MTBF calculation intuition

Bridge from I2C: Your documented sda_i gap becomes a CDC course lab — implement 2-FF sync, re-run TB, update review doc. That's a portfolio upgrade story.

Start with: CDC don'ts, async FIFO overview, multi-clock mindset.
