RTL Design / Module 1: Complete VLSI Flow
Lesson 1.3

Architecture — blocks, interfaces, clocks, power domains

Architecture is the map of the city before drawing every house. You decide the blocks, how they talk, which clocks they use, and which power islands exist — so RTL does not invent chaos later.

1

Blocks and hierarchy

Architecture deliverable: blocks, named interfaces, clocks, and power islands on one page.

Good architectures split by responsibility:

  • Datapath — compute / move data
  • Control — FSMs that sequence the datapath
  • Interfaces — I2C, UART, AXI, memory ports
  • CSR / register map — software-visible knobs

Rule of thumb: if two teams can argue about ownership of a signal, draw a block boundary and name the interface.

2

Interfaces beat spaghetti

Prefer clear protocols (valid/ready, req/ack, AXI-lite, I2C open-drain) over anonymous wires named flag3.

🔌

Named ports

Document width, direction, reset value, and clock domain on the diagram.

📦

Skid / FIFO

Decouple producers and consumers so timing and rate differ safely.

3

Clocks (where CDC begins)

Every flop lives in a clock domain. Crossing domains without a plan is a future silicon bug.

  • List every clock and its source (PLL, pad, divided).
  • Mark which blocks sit in which domain.
  • If a signal crosses domains, name the synchronizer strategy (Module 9 + CDC course).

Beginner trap: “We’ll just sample it; it’s slow.” Slow multi-bit buses still tear. Architecture must admit CDC early.

4

Power domains (awareness level)

Modern chips shut islands off. Architecture notes:

  • Which blocks can power-gate?
  • What must stay always-on (wake logic, RTC)?
  • Isolation / retention needs (you’ll meet these words again in DFT/PD).

You do not need UPF mastery yet — you need to not be surprised when power shows up in reviews.

5

Deliverable of architecture

  • One block diagram with clocks labeled
  • Interface list (widths + protocol)
  • Known CDC points
  • Register map outline (even a stub)

Even before full RTL, architects sketch the top-level ports — this is the “contract” between blocks:

i2c_master_if.v (port sketch)
module i2c_master (
  // Clock / reset (clk_sys domain)
  input  wire        clk,
  input  wire        rst_n,

  // CSR / host bus (simplified)
  input  wire        csr_we,
  input  wire [7:0]  csr_addr,
  input  wire [31:0] csr_wdata,
  output reg  [31:0] csr_rdata,
  output wire        irq,

  // I2C pads (open-drain style)
  inout  wire        scl,
  inout  wire        sda
);
  // Architecture note:
  // - Byte FSM + bit engine live here
  // - Document any CDC if pads/events are async
endmodule

🎯 What to remember

  • Architecture decides blocks, interfaces, clocks, and power before RTL details.
  • Named protocols beat mystery wires.
  • CDC and power must be drawn, not discovered accidentally.
