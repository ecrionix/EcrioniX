Lesson 1.6

DFT — scan, ATPG, BIST (hooks designers must leave)

Factories cannot open every chip and probe millions of nodes. Design-for-Test (DFT) adds structures so manufacturing can detect defects. RTL designers must not accidentally destroy those hooks.

1

Why DFT exists

Manufacturing defects happen (shorts, opens, stuck transistors). DFT answers: “Can we tell good die from bad die cheaply?”

💡 Airport security analogy

You cannot dismantle every suitcase. You design bags and scanners so problems are detectable quickly. DFT is the scanner-friendly suitcase design.

2

Scan (the big idea)

Scan stitches flops into a shift register during manufacturing test.

  • Flops can be stitched into scan chains in test mode.
  • Testers shift in patterns, pulse clocks, shift out results.
  • ATPG tools generate those patterns automatically.

You may not write scan RTL by hand early on — but your coding style (async resets, clock enables, latches) affects how easily scan can be inserted.

You rarely hand-code full scan, but you do respect a test-mode mux idea like this:

scan_mux_idea.v
// Conceptual — DFT tools usually insert this automatically
module scan_mux_idea (
  input  wire func_d,   // normal functional data
  input  wire scan_si,  // scan chain input
  input  wire scan_en,  // 1 = test/shift mode
  output wire d_to_flop
);
  assign d_to_flop = scan_en ? scan_si : func_d;
endmodule

// RTL habit that helps DFT:
// - Prefer sync resets / clear clock enables
// - Avoid unintentional latches and combo loops
// - Document every clock and async set/reset
3

BIST (built-in self-test)

Some blocks (memories especially) include on-chip pattern generators/checkers so external testers do less work.

Awareness level: if architecture says “memory BIST,” leave the interfaces and don’t “optimize away” test ports casually.

4

What RTL designers should remember

  • Prefer synchronous design styles that DFT tools like
  • Don’t invent sneaky latches or combo loops
  • Respect test-mode signals and lockup-latch guidance from DFT team
  • Document clocks/resets clearly — DFT depends on that map

You are not becoming a DFT engineer today. You are learning why “just combo hacks” create expensive DFT pain later.

🎯 What to remember

  • DFT makes manufacturing test possible at scale.
  • Scan + ATPG and BIST are the common vocabulary.
  • Clean, sync-friendly RTL is DFT-friendly RTL.
