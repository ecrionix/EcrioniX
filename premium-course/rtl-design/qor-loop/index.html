The QoR loop — write → lint → sim → synthesize → rewrite

Quality of Results (QoR) is not a one-shot gate — it is a loop. You write RTL, run checks, read reports, fix issues, and repeat until the block meets the team's bar for function, timing, area, CDC, and power. This lesson ties Module 9 together and points to Module 10 verification.

QoR loop

The iterative workflow every RTL engineer runs: implement → lint → simulate → synthesize → analyze reports → rewrite RTL → repeat until "done enough" for the milestone.

1

The loop — your daily rhythm

Early loops are fast (lint/sim). Later loops add synthesis. Don't skip straight to PNR — fix RTL issues cheaply first.

"Done enough" — milestone checklist

Perfection is not the bar at every checkpoint. Know what "done" means for each milestone:

MilestoneDone enough means
First RTL dropLint-clean (or waivers filed); sim passes directed tests; CDC protocol named per crossing
Feature completeSelf-checking TB; coverage on main modes; synthesis runs without error
RTL freeze candidateTiming met or known exceptions with fix plan; area within budget; CDC signoff started
RTL freezeAll waivers approved; no open functional bugs; timing/area signed by owner
  • Lint: zero ERROR severity (warnings reviewed or waived)
  • CDC: every crossing has Gray/FIFO/handshake — no raw buses
  • Sim: self-checking TB passes; key corner cases exercised
  • Timing: worst slack ≥ 0 at target frequency (or documented exception)
  • Area: within block budget or escalation filed
  • Power: clock enables on idle datapath; no combo clock gates
  • Documentation: interface spec updated for added pipeline latency

The full professional loop: Write RTL (Modules 1–7) → Pipeline for performance (Module 8) → Close QoR (Module 9) → Verify exhaustively (Module 10) → Integrate and tape out. You are now equipped for the verification half.

🎯 What to remember

  • QoR is a loop — write, lint, sim, synthesize, rewrite until milestone bar met.
  • Fix cheap issues early (lint, CDC structure) before expensive PNR iterations.
  • "Done enough" depends on milestone — know the checklist for each gate.
  • Module 9 complete — Module 10 adds verification depth to the same loop.
  • Track QoR metrics per iteration — don't merge on gut feel

Regression in the loop: After RTL freeze candidate, every QoR iteration runs the full regression suite — not just the one test you fixed. A timing fix that breaks a corner-case test is not progress.
