Primary Clock Definition

SDC 2.1

Defines an ideal master clock source on an input port or pin. Specifies the nominal period in nanoseconds and 50% or custom duty cycle edges.

# 500 MHz Primary Clock (2.0 ns period)
create_clock -name sys_clk -period 2.000 \
  -waveform {0.000 1.000} [get_ports clk_in]

# Clock Uncertainty (Jitter + Margin)
set_clock_uncertainty -setup 0.150 [get_clocks sys_clk]
set_clock_uncertainty -hold  0.050 [get_clocks sys_clk]

# Clock Transition (Slew)
set_clock_transition 0.080 [get_clocks sys_clk]

Generated Clock (PLL / Dividers)

SDC 2.1

Defines clocks derived internally from master clocks via PLL multipliers, ripple dividers, or clock gating cells. Preserves phase relationships.

# Divide-by-2 Internal Ripple Clock
create_generated_clock -name clk_div2 \
  -source [get_ports clk_in] \
  -divide_by 2 \
  [get_pins u_clk_div/clk_out]

# PLL 2x Multiplier Clock
create_generated_clock -name pll_clk_1ghz \
  -source [get_pins u_pll/REF_CLK] \
  -multiply_by 2 \
  [get_pins u_pll/OUT_CLK]

IO Timing Delays (Input & Output)

SDC 2.1

Constrains arrival times at chip boundary pins relative to external system clocks. Max delay governs setup; min delay governs hold.

# Input Delay on Data Bus (Setup max, Hold min)
set_input_delay -clock [get_clocks sys_clk] -max 0.650 [get_ports data_in[*]]
set_input_delay -clock [get_clocks sys_clk] -min 0.150 [get_ports data_in[*]]

# Output Delay on External Bus
set_output_delay -clock [get_clocks sys_clk] -max 0.700 [get_ports data_out[*]]
set_output_delay -clock [get_clocks sys_clk] -min -0.100 [get_ports data_out[*]]

Asynchronous Clock Groups (CDC)

SDC 2.1

Instructs OpenSTA / PrimeTime to ignore timing analysis between mutually asynchronous or multiplexed clock domains with synchronizers.

# Decouple Asynchronous Domains
set_clock_groups -asynchronous \
  -group [get_clocks {sys_clk clk_div2}] \
  -group [get_clocks {pcie_refclk pcie_pipe_clk}] \
  -group [get_clocks {jtag_tck}]

# Mutually Exclusive Multiplexed Clocks
set_clock_groups -logically_exclusive \
  -group [get_clocks clk_fast] \
  -group [get_clocks clk_slow]

Multicycle Paths

SDC 2.1

Relaxes timing on datapath operations enabled every N cycles (e.g. clock-enabled registers or slow floating-point arithmetic units).

# 2-Cycle Setup Multi-cycle Path
set_multicycle_path 2 -setup \
  -from [get_cells u_fpu/reg_a_reg[*]] \
  -to   [get_cells u_fpu/result_reg[*]]

# Adjust Hold to Preceding Edge (N-1 cycles)
set_multicycle_path 1 -hold \
  -from [get_cells u_fpu/reg_a_reg[*]] \
  -to   [get_cells u_fpu/result_reg[*]]

False Paths

SDC 2.1

Completely removes static, non-functional, or multi-cycle synchronizer paths from timing reports to prevent false timing violations.

# Asynchronous Reset Pins
set_false_path -from [get_ports rst_n]

# Quasi-Static Configuration Registers
set_false_path -from [get_cells u_csr/cfg_mode_reg[*]]

# 2-FF Synchronizer Cross-Paths
set_false_path -to [get_pins u_sync/*_meta_reg/D]

SVA Implication Operators

IEEE 1800

Antecedent-consequent conditional evaluation. Overlapping (|->) checks in the same cycle; non-overlapping (|=>) checks on the following clock cycle.

// Overlapping Implication (|->): Same Cycle
// If req is high, ack must be high in the SAME cycle
property p_same_cycle;
  @(posedge clk) disable iff (!rst_n)
  req |-> ack;
endproperty

// Non-Overlapping Implication (|=>): Next Cycle (##1)
// If start is high, busy must assert on NEXT clock cycle
property p_next_cycle;
  @(posedge clk) disable iff (!rst_n)
  start |=> busy;
endproperty

Sequence Repetition Operators

IEEE 1800

Matches repetitive patterns over consecutive or non-consecutive clock cycles across multi-beat streaming bursts.

// Consecutive Repetition: expr [*n]
// A is high for exactly 3 consecutive clock cycles
sequence s_burst3;
  A [*3]; // Equivalent to: A ##1 A ##1 A
endsequence

// Non-Consecutive Repetition: expr [=n]
// A occurs 3 times before completion, interspersed with !A
sequence s_non_consec;
  A [=3] ##1 B;
endsequence

// Goto Repetition: expr [->n]
// Matches when the 3rd occurrence of A happens exactly on this cycle
sequence s_goto;
  A [->3] ##1 B;
endsequence

SVA Sampled Value Functions

IEEE 1800

Inspect edge transitions, temporal signal stability, historical values from N cycles ago, and vector bit parity.

// Edge Detection Functions
$rose(sig)    // True if sig transitioned 0 -> 1
$fell(sig)    // True if sig transitioned 1 -> 0
$stable(sig)  // True if sig did NOT change value

// Past Value Access
$past(sig, 2) // Value of sig 2 clock cycles ago

// Vector Bit Health Checks
$onehot(bus)  // Exactly 1 bit is high (1'b1)
$onehot0(bus) // At most 1 bit is high (0 or 1 bit)
$isunknown(b) // Returns 1 if any bit is 'x' or 'z'

Protocol SVA: Ready-Valid Stability

IEEE 1800

Enforces ARM AMBA protocol compliance: Once TVALID is asserted, neither TVALID nor TDATA may change until TREADY is acknowledged.

property p_axi_valid_stable;
  @(posedge aclk) disable iff (!aresetn)
  tvalid && !tready |=> tvalid && $stable(tdata);
endproperty

assert_axi_valid: assert property (p_axi_valid_stable)
  else $error("[AXI PROTOCOL ERROR]: TVALID/TDATA changed before TREADY!");

AXI4 5-Channel Architecture

ARM AMBA

Full duplex, concurrent read and write operations across 5 independent unidirected channels with point-to-point ready-valid handshakes.

1. Write Address (AW): AWADDR, AWLEN, AWSIZE, AWBURST, AWVALID, AWREADY
2. Write Data (W):     WDATA, WSTRB, WLAST, WVALID, WREADY
3. Write Response (B): BRESP (OKAY, EXOKAY, SLVERR, DECERR), BVALID, BREADY
4. Read Address (AR):  ARADDR, ARLEN, ARSIZE, ARBURST, ARVALID, ARREADY
5. Read Data (R):      RDATA, RRESP, RLAST, RVALID, RREADY

APB4 State Machine & Handshake

ARM AMBA

Low-bandwidth, low-power register configuration bus. Two-phase non-pipelined transfer with wait-state support via PREADY.

// 1. IDLE Phase: PSEL = 0, PENABLE = 0
// 2. SETUP Phase: PSEL = 1, PENABLE = 0, PADDR/PWRITE/PWDATA valid (1 cycle)
// 3. ACCESS Phase: PSEL = 1, PENABLE = 1
//    -> If PREADY = 0: Slave extends transfer with wait states
//    -> If PREADY = 1: Transfer completes; capture PRDATA or sample PSLVERR

AXI Burst Types & Wrapping Boundaries

ARM AMBA

Address increment modes for multi-beat bursts (AWLEN/ARLEN beats = LEN + 1).

// 2'b00 FIXED: Address remains static (FIFO read/write)
// 2'b01 INCR:  Linear increment: Addr = Addr + (1 << SIZE)
// 2'b10 WRAP:  Circular cache-line fill. Wraps at boundary:
//              Wrap_Boundary = (INT(Addr / (Bytes * Len))) * (Bytes * Len)

Cliff Cummings' Core CDC Rules

Synthesis Standard

Fundamental architectural rules to eliminate multi-clock domain race hazards and metastability failures in silicon.

1. Never synchronize multi-bit binary buses with multiple 2-FF synchronizers (use Gray code or handshake).
2. Only 1 bit may transition per clock cycle across asynchronous boundaries.
3. Pulse width in source domain must exceed 1.5x destination clock period (or use toggle synchronizer).
4. Register all signals in source domain before driving synchronizer inputs.
5. Place ASYNC_REG = "TRUE" on synchronizer flip-flops to force adjacent placement.

Mean Time Between Failures (MTBF)

Synthesis Standard

Mathematical calculation of synchronizer reliability against metastability settling failures.

MTBF = exp(t_resolve / tau) / (T0 * f_clk * f_data)

Where:
- t_resolve: Available settling slack (T_period - T_setup)
- tau: Flip-flop resolution time constant (process dependent)
- T0: Metastability aperture window (~10-15 fs in FinFET)
- f_clk: Destination clock frequency
- f_data: Asynchronous input toggle frequency

Non-Linear Delay Model (NLDM) 7x7 Table

Liberty (.lib)

Standard cell propagation delay is characterized as a 2D lookup table indexed by input transition time (slew) and output capacitive load.

cell (NAND2_X1) {
  pin (Y) {
    direction : output;
    function : "!(A & B)";
    timing () {
      related_pin : "A";
      timing_sense : negative_unate;
      cell_rise (delay_template_7x7) {
        index_1 ("0.01, 0.03, 0.07, 0.15, 0.30, 0.60, 1.20"); /* Input Transition (ns) */
        index_2 ("0.001, 0.005, 0.015, 0.035, 0.075, 0.150, 0.300"); /* Output Load (pF) */
        values ( \
          "0.021, 0.028, 0.045, 0.082, 0.158, 0.302, 0.589", \
          "0.025, 0.032, 0.049, 0.086, 0.162, 0.306, 0.593", \
          ... /* Bilinear interpolation between matrix entries */
        );
      }
    }
  }
}

Flip-Flop Setup & Hold Timing Arc

Liberty (.lib)

Models setup and hold constraints relative to the clock pin transition time and data pin transition time.

timing () {
  related_pin : "CLK";
  timing_type : setup_rising;
  rise_constraint (constraint_template_3x3) {
    index_1 ("0.02, 0.10, 0.50"); /* Data Slew */
    index_2 ("0.02, 0.10, 0.50"); /* Clock Slew */
    values ( \
      "0.045, 0.052, 0.078", \
      "0.048, 0.055, 0.081", \
      "0.062, 0.069, 0.095"  \
    );
  }
}
