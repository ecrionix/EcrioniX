3-Hour Interactive Workshop Syllabus: "From RTL to GDSII"

Ready-to-use curriculum for student branches, IEEE workshops, and college technical festivals.

=============================================================================
WORKSHOP TITLE: Modern RTL Microarchitecture & Open-Source Silicon Flow
TARGET AUDIENCE: 2nd–4th Year ECE, EEE, and Computer Engineering Students
PREREQUISITES: Basic Boolean logic gates and basic binary number systems
TOOLS USED: EcrioniX In-Browser EDA Suite (No installation required)
=============================================================================

HOUR 1: SYNTHESIZABLE VERILOG & HARDWARE ARCHITECTURE (60 Mins)
- 00:00–00:15: The Hardware Mental Model: Why Verilog is NOT C code.
- 00:15–00:35: The IEEE Stratified Event Queue: Active vs NBA (Non-Blocking) regions.
               Live Demo: Simulating race conditions and latch inference.
- 00:35–00:60: Finite State Machine (FSM) Design: Moore vs Mealy output latency.
               Hands-on Exercise: Sequence detector "1011" with overlap.

HOUR 2: STATIC TIMING ANALYSIS & CONSTRAINTS (60 Mins)
- 00:00–00:20: Understanding Clock Propagation, Setup Time, and Hold Time.
               Equations: Setup Slack = T_req - T_arr; Hold Slack = T_arr - T_req.
- 00:20–00:40: Hands-on Tool: Setup & Hold Slack Solver on EcrioniX.
               Deriving Maximum Operating Frequency (Fmax) under clock skew.
- 00:40–00:60: Synopsys Design Constraints (SDC): create_clock, IO delays, and false paths.

HOUR 3: OPEN-SOURCE ASIC FLOW: RTL TO GDSII (60 Mins)
- 00:00–00:25: The Automated ASIC Flow: Yosys Synthesis -> Floorplanning -> Placement -> CTS -> Routing.
- 00:25–00:45: Interactive Lab: Running OpenROAD on SkyWater SKY130 PDK inside EcrioniX.
- 00:45–00:60: Gate-Level Simulation (GLS) with SDF Timing Back-Annotation. Q&A and next steps.
