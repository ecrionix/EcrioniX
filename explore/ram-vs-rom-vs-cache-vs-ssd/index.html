Non-Volatile Firmware

ROM Explained: What Does Your Computer Remember When Power is OFF?

ROM stands for Read-Only Memory. When your computer is unplugged, volatile RAM loses its state completely. How does the CPU know what to do when you press the power button? It reads hardwired instructions from non-volatile firmware.

Standard Hardware Boot Sequence

When power arrives, the CPU execution sequence follows these standardized architectural phases:

[Phase 1] Power Supply: PSU stabilizes voltages and asserts Power-Good signal.
[Phase 2] Reset Vector: CPU initializes program counter to hardwired vector (0xFFFFFFF0).
[Phase 3] Firmware Execution: CPU reads UEFI/BIOS instructions from SPI Flash ROM.
[Phase 4] Hardware POST: Power-On Self-Test initializes memory controllers, PCIe buses, display.
[Phase 5] OS Handoff: Bootloader reads OS kernel from SSD into RAM. OS assumes full control!

SSD Explained: Where Does Your Data Go When You Save a File?

Solid State Drives contain zero mechanical moving parts. Instead of spinning platters, they store billions of bits as microscopic electrical charges trapped inside non-volatile floating-gate or charge-trap NAND transistors.

The Golden SSD Rule:

NAND Flash can be written in Pages (typically 4 KB – 16 KB), but can only be erased in entire Blocks (typically 2 MB – 8 MB). You cannot overwrite a single page directly without copying valid pages and erasing the whole block!

SSD Controller Brain:

The SSD controller runs firmware managing Wear Leveling (distributing writes evenly across silicon so cells don't burn out prematurely), ECC (Error Correction Code), and TRIM.

Deep-Dive Computer Architecture

Go Deeper: Advanced Silicon Memory Principles

Explore the circuit physics, cache associativity algorithms, and multi-core coherence protocols that power modern processors.

1. SRAM vs. DRAM: Circuit Physics & Transistor Topology ▼

The difference between Cache and RAM stems from their transistor-level circuit design:

  • Static RAM (SRAM, 6T Cell): Uses 6 transistors forming two cross-coupled CMOS inverters with two pass transistors. Because the circuit is a bistable multivibrator latch, it retains its stored logical state indefinitely as long as DC power is supplied. It requires no refresh cycles and switches state in sub-nanosecond intervals. However, 6 transistors per bit consume significant silicon area.
  • Dynamic RAM (DRAM, 1T-1C Cell): Stores each bit as electrical charge on a microscopic trench or stacked capacitor, accessed via a single MOSFET pass transistor. Because silicon junction leakage causes the capacitor charge to decay within milliseconds, DRAM requires an active refresh command every 64 ms (JEDEC standard), reading the charge with high-gain sense amplifiers and writing it back. This dynamic refresh makes DRAM slower, but a 1T-1C cell is up to 20× smaller than a 6T SRAM cell, enabling affordable 32 GB DIMMs.
2. Cache Associativity: Direct-Mapped vs. Set-Associative vs. Fully Associative ▼

When a 64-byte block of memory is cached, where can it be placed?

  • Direct-Mapped: Each memory address maps to exactly one specific cache line (`Index = Address % Number of Lines`). It requires minimal comparison hardware (fastest lookup), but suffers severe conflict misses if two frequently used variables hash to the same line.
  • N-Way Set-Associative: The cache is divided into sets, each containing $N$ lines (e.g. 8-way or 16-way associative). An address maps to one set, but can reside in any of the $N$ ways within that set. A parallel tag comparator checks all $N$ ways simultaneously. This represents the gold standard used in modern L1, L2, and L3 caches.
  • Fully Associative: A memory block can reside in any cache line. Eliminates conflict misses entirely, but requires an associative comparator for every single line in the cache, limiting its use to small structures like Translation Lookaside Buffers (TLBs).
3. Multi-Core Cache Coherence: The MESI Protocol ▼

In a modern 8-core CPU, each core has its own private L1 and L2 cache. If Core 0 modifies variable `X = 5` in its private L1 cache, what prevents Core 4 from reading a stale copy of `X = 0` from its own L1 cache?

Hardware enforces Cache Coherence via the MESI Protocol (or MOESI in AMD processors):

  • Modified (M): The cache line is present only in the current cache and is dirty (modified relative to main memory).
  • Exclusive (E): The cache line is present only in the current cache and is clean (matches memory).
  • Shared (S): The cache line may be present in multiple cores' caches simultaneously (read-only sharing).
  • Invalid (I): The cache line does not contain valid data.

Cores broadcast invalidation messages across the on-die ring/mesh interconnect ("Bus Snooping"), forcing other cores to invalidate their local copies before a write proceeds.

4. Virtual Memory, Page Tables & The Memory Management Unit (MMU) ▼

Applications do not access physical RAM addresses directly. Every program runs inside an isolated 64-bit Virtual Address Space.

The hardware Memory Management Unit (MMU) inside the CPU translates virtual addresses into physical RAM addresses using multi-level Page Tables stored in memory. To accelerate this translation, the CPU caches recent translations in a specialized ultra-fast associative cache called the Translation Lookaside Buffer (TLB).

If an application requests memory that has been paged out to the SSD due to high memory pressure, a Page Fault interrupt is triggered, pausing the thread while the OS kernel reads the missing page from the SSD back into RAM.

5. 3D NAND Flash Cell Physics: SLC, MLC, TLC, and QLC ▼

NAND Flash cells store bits by trapping electrons inside an insulated floating gate or silicon nitride charge trap layer. The number of bits stored per physical cell determines capacity, speed, and endurance:

  • SLC (Single-Level Cell): 1 bit per cell (2 voltage levels). Fastest writes, highest endurance (~100,000 P/E cycles). Used in enterprise mission-critical caches.
  • MLC (Multi-Level Cell): 2 bits per cell (4 voltage levels). Good balance, ~10,000 cycles.
  • TLC (Triple-Level Cell): 3 bits per cell (8 voltage levels). The standard in modern consumer SSDs (~3,000 cycles).
  • QLC (Quad-Level Cell): 4 bits per cell (16 precise voltage levels). Highest storage density and lowest cost, but lower endurance (~1,000 cycles) and slower raw write speeds. Modern QLC drives use dynamic SLC caching to maintain snappy burst performance.
