Computer Arithmetic Theory & FAQ

How does a CPU subtract numbers using only addition gates?
Processors calculate subtraction A - B by adding the two's complement of B:

A - B = A + (~B + 1) = A + (~B) + 1

By feeding operand B through an array of XOR gates with the Mode control bit M = 1, each bit is inverted (B ⊕ 1 = ~B). Injecting Cin = M = 1 into the least-significant bit (Bit 0) adds the required +1. When M = 0, the XOR gates pass B unchanged and Cin = 0, executing regular addition. This elegant trick reuses 100% of the adder hardware for subtraction.
What is the difference between Carry Out (C) and Signed Overflow (V)?
Carry Out (C) applies to unsigned numbers. It indicates whether the result exceeded the N-bit capacity (e.g., 1111 (15) + 0001 (1) = 10000 (16)).

Signed Overflow (V) applies to signed two's complement numbers. It occurs when two positive numbers produce a negative result, or two negative numbers produce a positive result (e.g., +7 (0111) + +1 (0001) = -8 (1000)). In digital hardware, overflow is detected using a single XOR gate comparing the carry into the sign bit with the carry out of the sign bit: V = C3 ⊕ C4.
Why do processors avoid Ripple Carry Adders in 32-bit and 64-bit ALUs?
In a Ripple Carry Adder (RCA), the carry bit must sequentially propagate through every bit slice from LSB to MSB. For 32 bits, the worst-case propagation delay requires 32 full adder carry delays. Modern 32-bit and 64-bit CPUs use Carry Lookahead Adders (CLA), Kogge-Stone, or Brent-Kung parallel prefix adders that compute all carries in $O(\log_2 N)$ gate delays using Generate ($G = A \cdot B$) and Propagate ($P = A \oplus B$) logic.
