module top_module(
  input   clk,
  input   areset_n,
  input   en,
  input   d,
  output reg q
);
  always @(posedge clk or negedge areset_n) begin
    if (!areset_n)
      q <= 1'b0;
    else if (en)
      q <= d;
  end
endmodule

Architectural Deep Dive & Implementation Walkthrough
A clock enable controls whether new data updates the flip-flop. Rather than gating the clock tree (which can introduce clock skew and glitches), FPGA synthesis maps this to the dedicated clock-enable (`CE`) pin on slice flip-flops, or synthesizes a recirculating multiplexer ($q_{next} = en \cdot d + \overline{en} \cdot q$).


      
Common RTL Designer Pitfalls
⚠️ Common Mistakes to Avoid
['Attempting to gate the clock in RTL: `assign gated_clk = clk & en; always @(posedge gated_clk)`. NEVER do this in synthesizable RTL due to clock skew, race conditions, and glitches.', 'Placing `en` inside the sensitivity list.']


      
Silicon & Hardware Engineering Notes
🛠️ ASIC vs FPGA Hardware Considerations
Always prefer synchronous clock enables over manual clock gating logic. For ASIC low-power design, use dedicated Integrated Clock Gating (ICG) cells instantiated from the vendor library.
