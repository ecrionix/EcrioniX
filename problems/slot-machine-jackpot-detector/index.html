Slot Machine Jackpot Detector

Fun & Games · combinational, comparator

Judge a 3-reel slot machine spin: jackpot when all three reels match, a smaller near-miss flag when exactly two do.

Module Specification
Write a synthesizable Verilog module named top_module matching the ports below exactly.
Concept: A true jackpot requires all three reels to agree: jackpot=(reel1==reel2)&&(reel2==reel3);, with two_match catching the near-miss case where only some pair agrees. The easy mistake is checking only one pair (say reel1==reel2) and calling that the jackpot condition — it correctly fires when all three genuinely match, but it also fires whenever just the first two happen to match and the third is completely different, awarding a jackpot for what should only ever be a two-reel near-miss.
