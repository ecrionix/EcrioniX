Vending Machine FSM (15-Cent)

Sequential Design · sequential, fsm

A classic textbook FSM: accept nickels and dimes, and dispense as soon as the running total reaches 15 cents (no change given).

Module Specification
Write a synthesizable Verilog module named top_module matching the ports below exactly.
⚡ Timing & Synthesizability Constraints

Timing Contract: Combinational zero-delay logic or single-cycle register transfer.

RTL Constraints: Synthesizable Verilog-2001. No # delays.

Concept: Track cents in a register. Compute next_cents combinationally from the current total plus whatever coin is inserted this cycle; dispense is simply (next_cents >= 15). On the clock edge, if the threshold was reached, reset the total to 0 instead of carrying it forward (no change is given for overpayment).
