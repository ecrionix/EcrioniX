DMA Descriptor Beat Counter

Sequential Design · sequential, counter, dma

Track remaining beats in a DMA transfer as they complete, guarding against the stray late-arriving pulse that real pipelined DMA engines can produce after completion.

Module Specification
Write a synthesizable Verilog module named top_module matching the ports below exactly.
Concept: The remaining-beats counter must never decrement past 0 — if(beat_done && beats_remaining!=0) beats_remaining<=beats_remaining-1 — because a real DMA engine's completion pulses can arrive slightly out of sync with the counter due to pipeline latency, and a stray extra pulse after the transfer is already done is a normal, expected occurrence, not an error. Skip the guard and that harmless extra pulse underflows the counter to 255, which then flips xfer_complete back to 0 — telling the rest of the system a finished transfer is somehow still in progress.
