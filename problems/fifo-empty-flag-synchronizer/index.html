Async-FIFO Empty Flag Synchronizer

Sequential Design · sequential, cdc, protocol

Synchronize a Gray-coded write pointer into the read domain and compare it against the local read pointer to generate a reliable empty flag — the core of every async FIFO.

Module Specification
Write a synthesizable Verilog module named top_module matching the ports below exactly.
Concept: An async FIFO's write pointer lives in the write clock domain but the empty flag is needed in the read domain, so the pointer must cross safely — Gray coding ensures only one bit ever changes per increment, so even a partially-synchronized value during a transition is never wildly wrong. Double-flop the incoming Gray pointer (meta, then wptr_gray_sync), then compare it against the local read pointer: empty <= (wptr_gray_sync == rptr_gray). Comparing the raw unsynchronized pointer directly against the local one skips the synchronizer chain entirely, reintroducing metastability risk into the empty flag.
