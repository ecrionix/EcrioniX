⚡ Timing & Synthesizability Constraints

Timing Contract: Strict synchronous timing aligned to posedge clk or zero-delay combinational propagation.

RTL Constraints: Synthesizable Verilog-2001. No # delays in synthesizable RTL.

Concept: A register file's read ports are almost always combinational — assign rdata1=regs[raddr1] — so a freshly-written value is visible to a read the very same cycle it commits, with no extra latency. Accidentally registering the read path (adding a clocked flop between the memory array and the output) is a very common real bug, and a sneaky one: it doesn't break anything obviously, it just delays every read by exactly one clock cycle, so a value written this cycle silently isn't visible until the cycle after — a timing bug that only shows up when something downstream expects same-cycle forwarding.

Problem Statement & Requirements

      
The classic RTL building block behind every processor datapath: 8 registers, one synchronous write port, and three fully independent asynchronous read ports.

      
Hardware design teams at leading semiconductor firms evaluate these exact port contracts, race-condition assertions, and corner cases during technical design reviews and ASIC engineer interviews.

      
      
Concept: A register file's read ports are almost always combinational — assign rdata1=regs[raddr1] — so a freshly-written value is visible to a read the very same cycle it commits, with no extra latency. Accidentally registering the read path (adding a clocked flop between the memory array and the output) is a very common real bug, and a sneaky one: it doesn't break anything obviously, it just delays every read by exactly one clock cycle, so a value written this cycle silently isn't visible until the cycle after — a timing bug that only shows up when something downstream expects same-cycle forwarding.

What does 3-Read / 1-Write Register File require?
The classic RTL building block behind every processor datapath: 8 registers, one synchronous write port, and three fully independent asynchronous read ports. Implement it as Verilog module top_module matching the listed ports.

      
Is this design combinational or sequential?
Tags: sequential, memory, datapath. If a clock signal is present in the port table, implement it as sequential logic; otherwise, use continuous assignments or combinational blocks.

A hidden SystemVerilog testbench simulates your module in the cloud judge. You pass when all directed corner cases match the golden model and the VCD timing waveform matches the contract.
