Verified Synthesizable RTL 
module top_module (
  input  wire       clk,
  input  wire       rst_n,
  input  wire       push,
  input  wire       pop,
  input  wire [3:0] almost_full_thresh,
  input  wire [3:0] almost_empty_thresh,
  output wire       almost_full,
  output wire       almost_empty,
  output wire       full,
  output wire       empty,
  output reg  [4:0] occupancy
);

  assign full  = (occupancy == 5'd16);
  assign empty = (occupancy == 5'd0);

  assign almost_full  = (occupancy >= {1'b0, almost_full_thresh});
  assign almost_empty = (occupancy <= {1'b0, almost_empty_thresh});

  wire valid_push = push && (!full || pop);
  wire valid_pop  = pop && !empty;

  always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
      occupancy <= 5'd0;
    end else begin
      case ({valid_push, valid_pop})
        2'b10: occupancy <= occupancy + 5'd1;
        2'b01: occupancy <= occupancy - 5'd1;
        default: ; // 2'b00 or 2'b11 -> maintain count
      endcase
    end
  end

endmodule

Architectural Deep Dive & Implementation Walkthrough
DMA Flow Control Using Watermarks


Direct Memory Access (DMA) controllers cannot wait until a buffer is completely full or completely empty before issuing bus requests. Doing so leads to buffer under-run or bus under-utilization.


Watermark Thresholds


    
  
  • Almost Full Watermark: Warns the DMA scatter-gather engine that the buffer is reaching capacity (e.g. 12/16 slots), allowing it to throttle upstream producers before overflow occurs.
    • 
  
  • Almost Empty Watermark: Signals that the buffer is nearly drained (e.g. 2/16 slots), prompting a burst read request to refill it before underflow occurs.
    • 



      
Common RTL Designer Pitfalls
⚠️ Common Mistakes to Avoid
Using a 4-bit counter for a depth-16 buffer, which wraps around from 15 to 0 instead of reaching 16.


      
Silicon & Hardware Engineering Notes
🛠️ ASIC vs FPGA Hardware Considerations
High-performance PCIe Root Complexes use programmable watermark thresholds to tune DMA burst lengths according to payload MTU.
