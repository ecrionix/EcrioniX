4-Channel Packet-Locked Chiplet Scheduler

Advanced RTL & Protocol Design · advanced-rtl, arbitration-and-interconnect, systemverilog, asic, fpga

Design a 4-channel packet scheduler ensuring complete packet atomicity and fair round-robin scheduling across chiplet ingress queues.

Module Specification
Write a synthesizable Verilog module named top_module matching the ports below exactly.
📐 Circuit Schematic Diagram
⚡ Timing & Synthesizability Constraints

Timing Contract: Clocked on posedge clk with active-low rst_n. Grant locked strictly between SOP and EOP. Priority pointer advances on EOP transfer.

RTL Constraints: Zero packet interleaving. Synthesizable Verilog-2001.

Objective: Implement a packet scheduler serving 4 ingress queues. Each channel delivers flits with ch_valid, ch_sop (start-of-packet), and ch_eop (end-of-packet). Once granted, lock arbitration onto the active channel until ch_eop completes, preventing packet interleaving under downstream backpressure.

Prerequisites: Packet boundary tracking (SOP/EOP), packet-level arbitration, round-robin fairness.

module top_module (
  input  wire         clk,
  input  wire         rst_n,
  input  wire [3:0]   ch_valid,
  output reg  [3:0]   ch_ready,
  input  wire [3:0]   ch_sop,
  input  wire [3:0]   ch_eop,
  input  wire [127:0] ch_data,
  output reg          out_valid,
  input  wire         out_ready,
  output reg          out_sop,
  output reg          out_eop,
  output reg  [31:0]  out_data
);

  reg [1:0] active_ch;
  reg [1:0] rr_ptr;
  reg       locked;

  wire [31:0] ch_in [0:3];
  assign ch_in[0] = ch_data[31:0];
  assign ch_in[1] = ch_data[63:32];
  assign ch_in[2] = ch_data[95:64];
  assign ch_in[3] = ch_data[127:96];

  // Pick next candidate channel
  reg [1:0] next_pick;
  reg       has_candidate;

  always @(*) begin
    has_candidate = 1'b0;
    next_pick     = rr_ptr;
    if (ch_valid[rr_ptr] && ch_sop[rr_ptr]) begin
      has_candidate = 1'b1;
      next_pick     = rr_ptr;
    end else if (ch_valid[(rr_ptr + 2'd1) & 2'd3] && ch_sop[(rr_ptr + 2'd1) & 2'd3]) begin
      has_candidate = 1'b1;
      next_pick     = (rr_ptr + 2'd1) & 2'd3;
    end else if (ch_valid[(rr_ptr + 2'd2) & 2'd3] && ch_sop[(rr_ptr + 2'd2) & 2'd3]) begin
      has_candidate = 1'b1;
      next_pick     = (rr_ptr + 2'd2) & 2'd3;
    end else if (ch_valid[(rr_ptr + 2'd3) & 2'd3] && ch_sop[(rr_ptr + 2'd3) & 2'd3]) begin
      has_candidate = 1'b1;
      next_pick     = (rr_ptr + 2'd3) & 2'd3;
    end
  end

  // Combinational output muxing
  always @(*) begin
    ch_ready = 4'b0000;
    if (locked) begin
      out_valid           = ch_valid[active_ch];
      out_sop             = ch_sop[active_ch];
      out_eop             = ch_eop[active_ch];
      out_data            = ch_in[active_ch];
      ch_ready[active_ch] = out_ready;
    end else if (has_candidate) begin
      out_valid          = ch_valid[next_pick];
      out_sop            = ch_sop[next_pick];
      out_eop            = ch_eop[next_pick];
      out_data           = ch_in[next_pick];
      ch_ready[next_pick] = out_ready;
    end else begin
      out_valid = 1'b0;
      out_sop   = 1'b0;
      out_eop   = 1'b0;
      out_data  = 32'h0;
    end
  end

  always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
      active_ch <= 2'd0;
      rr_ptr    <= 2'd0;
      locked    <= 1'b0;
    end else begin
      if (!locked) begin
        if (has_candidate) begin
          active_ch <= next_pick;
          if (out_valid && out_ready && out_eop) begin
            // Single-beat packet (SOP && EOP same beat)
            locked <= 1'b0;
            rr_ptr <= (next_pick + 2'd1) & 2'd3;
          end else if (out_valid && out_ready) begin
            locked <= 1'b1;
          end
        end
      end else begin
        if (out_valid && out_ready && out_eop) begin
          locked <= 1'b0;
          rr_ptr <= (active_ch + 2'd1) & 2'd3;
        end
      end
    end
  end

endmodule

Architectural Deep Dive & Implementation Walkthrough
Packet Framing and Head-of-Line Blocking


Packet multiplexers in PCIe, Ethernet, and UCIe architectures must guarantee packet atomicity: once a packet's Start of Packet (SOP) is emitted, no other channel may transmit until the End of Packet (EOP) is acknowledged.


Arbitration and Locking Cycle


    
  
  1. Channel Selection: The arbiter identifies requesting channels that have SOP = 1. It uses round-robin fairness to select the next winner.
    2. 
  
  2. Atomicity Lock: The arbiter enters the locked state, routing only the winning channel's data beats to the egress port.
    3. 
  
  3. Release: When EOP handshakes with the consumer, the lock drops and the priority pointer advances.

Common RTL Designer Pitfalls
⚠️ Common Mistakes to Avoid
Allowing non-SOP beats to trigger arbitration, or failing to lock the grant when downstream pauses (out_ready = 0).


      
Silicon & Hardware Engineering Notes
🛠️ ASIC vs FPGA Hardware Considerations
Advanced NoCs use virtual channels (VCs) to prevent head-of-line blocking when one destination is congested.
