Design a toggle-based pulse synchronizer capable of reliably transferring 1-cycle event pulses between fast-to-slow and slow-to-fast clock domains.

⚡ Timing & Synthesizability Constraints

Timing Contract: Completely asynchronous src_clk and dst_clk. Ensure consecutive pulses in src_clk are separated by at least 3 dst_clk periods to prevent pulse collisions.

RTL Constraints: No missed pulses. Synthesizable Verilog-2001.

Objective: Implement a pulse synchronizer. Directly synchronizing a 1-cycle pulse from a fast clock domain into a slower clock domain often fails because the pulse can vanish between slow clock edges. Use a toggle register in the source domain, cross the level signal through a 2-flop synchronizer in the destination domain, and use an edge detector (XOR) to generate an exact 1-cycle pulse in the destination domain.

module top_module (
  input  wire src_clk,
  input  wire src_rst_n,
  input  wire src_pulse,
  input  wire dst_clk,
  input  wire dst_rst_n,
  output reg  dst_pulse
);

  reg src_toggle;
  reg dst_s1, dst_s2, dst_s3;

  // Source domain: Pulse-to-Toggle
  always @(posedge src_clk or negedge src_rst_n) begin
    if (!src_rst_n) begin
      src_toggle <= 1'b0;
    end else if (src_pulse) begin
      src_toggle <= ~src_toggle;
    end
  end

  // Destination domain: 2-Flop Sync + 3rd Flop for Edge Detection
  always @(posedge dst_clk or negedge dst_rst_n) begin
    if (!dst_rst_n) begin
      dst_s1    <= 1'b0;
      dst_s2    <= 1'b0;
      dst_s3    <= 1'b0;
      dst_pulse <= 1'b0;
    end else begin
      dst_s1    <= src_toggle;
      dst_s2    <= dst_s1;
      dst_s3    <= dst_s2;
      dst_pulse <= dst_s2 ^ dst_s3; // Pulses on ANY transition (0->1 or 1->0)
    end
  end

endmodule

Architectural Deep Dive & Implementation Walkthrough
The Pulse Swallowing Problem in CDC


When sending a 1-clock-cycle pulse from a fast clock domain (e.g. 500 MHz, 2 ns width) to a slow clock domain (e.g. 50 MHz, 20 ns period), the pulse frequently asserts and deasserts entirely between two rising edges of the slow clock. A direct 2-flop synchronizer will miss the pulse completely.


Toggle-Based Pulse Synchronization


    
  
  1. Pulse to Toggle: In the source domain, a T-type flip-flop toggles its state ($0 	o 1$ or $1 	o 0$) whenever src_pulse = 1 occurs. This transforms a transient pulse into a permanent DC level change.
    2. 
  
  2. Level Synchronization: The toggle level crosses into the destination domain via a standard 2-flop synchronizer.
    3. 
  
  3. Edge Detection: In the destination domain, a third register stores the delayed state. An XOR between the 2nd and 3rd flops detects any state transition, generating a clean 1-cycle pulse in the destination clock domain.
    4. 



      
Common RTL Designer Pitfalls
⚠️ Common Mistakes to Avoid
Using a simple rising-edge detector (in & ~in_d) instead of an XOR. Since the source toggles both 0->1 and 1->0, an XOR is required to detect every pulse.


      
Silicon & Hardware Engineering Notes
🛠️ ASIC vs FPGA Hardware Considerations
Consecutive source pulses must be separated by at least 2.5 destination clock periods to allow the toggle transition to propagate through the synchronizer chain.
