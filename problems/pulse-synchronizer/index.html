💡 Need Guidance? Progressive Hints (3 Levels)
Hint 1: Conceptual Direction & Hardware Primitives
A fast pulse cannot be sampled directly by a slow clock because the pulse might vanish between slow clock edges.
Hint 2: Implementation Architecture & Approach
Solution: Convert the pulse into a level toggle: `src_toggle <= ~src_toggle;`.
Hint 3: Edge Cases, Timing & Verilog Syntax
Synchronize `src_toggle` into `clk_dst` with a 2-flop synchronizer, then detect transitions with an XOR edge detector (`dst_q2 ^ dst_q3`).

Verified Synthesizable RTL 
module top_module(
  input   clk_src,
  input   areset_src_n,
  input   pulse_src,
  input   clk_dst,
  input   areset_dst_n,
  output  pulse_dst
);
  reg src_toggle;

  // Step 1: In source domain, toggle on each pulse
  always @(posedge clk_src or negedge areset_src_n) begin
    if (!areset_src_n)
      src_toggle <= 1'b0;
    else if (pulse_src)
      src_toggle <= ~src_toggle;
  end

  // Step 2: Synchronize toggle level across CDC into clk_dst using 2 flops
  reg dst_q1, dst_q2, dst_q3;
  always @(posedge clk_dst or negedge areset_dst_n) begin
    if (!areset_dst_n) begin
      dst_q1 <= 1'b0;
      dst_q2 <= 1'b0;
      dst_q3 <= 1'b0;
    end else begin
      dst_q1 <= src_toggle;
      dst_q2 <= dst_q1;
      dst_q3 <= dst_q2;
    end
  end

  // Step 3: Edge detector (XOR detects both 0->1 and 1->0 toggle transitions)
  assign pulse_dst = dst_q2 ^ dst_q3;
endmodule

⚡ Synthesizable Implementation Guidelines

        

          
Timing Contract: Input `pulse_src` is a single-cycle strobe in `clk_src`. Output `pulse_dst` asserts for exactly 1 cycle in `clk_dst`.

          
Synthesis Constraints: Consecutive pulses must be spaced far enough apart to allow toggle completion in the slow domain.

        

      


      
Architectural Deep Dive & Implementation Walkthrough
If a pulse in a 500 MHz domain is 2 ns wide, a 50 MHz clock (20 ns period) would easily miss it. By toggling a register on every pulse, the level stays persistent indefinitely until the slow clock samples it. An XOR gate across the synchronized delayed stages detects both rising and falling toggle transitions, reconstructing an exact 1-cycle pulse in the destination domain.


      
Common RTL Designer Pitfalls
⚠️ Common Mistakes to Avoid
['Sending a second pulse before the first pulse has been sampled in the destination domain, causing pulse collision/loss.', 'Using a simple edge detector (`dst_q2 & ~dst_q3`) instead of XOR (`dst_q2 ^ dst_q3`), which misses every alternate pulse.']


      
Silicon & Hardware Engineering Notes
🛠️ ASIC vs FPGA Hardware Considerations
Ensure the pulse rate in the fast domain is less than twice the period of the slow clock domain, or use an asynchronous handshake/FIFO.
