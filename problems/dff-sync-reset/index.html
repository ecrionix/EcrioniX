module top_module(
  input   clk,
  input   sync_rst,
  input   d,
  output reg q
);
  always @(posedge clk) begin
    if (sync_rst)
      q <= 1'b0;
    else
      q <= d;
  end
endmodule

Architectural Deep Dive & Implementation Walkthrough
Synchronous reset acts as a data filter: glitches on the reset line are completely rejected unless they align with the active clock edge. In high-frequency FPGA designs (like AMD UltraScale), synchronous resets map cleanly into native control sets without wasting routing resources.

Silicon & Hardware Engineering Notes
🛠️ ASIC vs FPGA Hardware Considerations
Synchronous reset ensures 100% synchronous timing closure and eliminates reset recovery/removal checks. However, resetting a block requires the clock to be running.
