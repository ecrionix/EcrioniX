Glitch-Free Clock Multiplexer with Handshake Feedback

Advanced RTL & Protocol Design · advanced-rtl, soc-controllers, systemverilog, asic, fpga

Design an industry-standard glitch-free clock switching controller that prevents runt pulses when dynamically alternating between asynchronous clock sources.

Module Specification

⚡ Timing & Synthesizability Constraints

Timing Contract: Driven by asynchronous clock sources clk_0 and clk_1 with active-low async rst_n. Enables must toggle ONLY during clock low phases.

RTL Constraints: Strictly zero runt pulses on out_clk. No glitches during select transitions. Synthesizable Verilog-2001.

Objective: Implement a glitch-free dual-clock multiplexer. Use negative-edge flip-flop synchronizers with mutual exclusion feedback. When select changes, the currently active clock is first disabled when low, followed by enabling the target clock on its negative edge, guaranteeing zero runt pulses or glitches.

Prerequisites: Clock gating, dynamic frequency scaling (DFS), negative-edge synchronizers, runt pulse hazards, CDC.

module top_module (
  input  wire clk_0,
  input  wire clk_1,
  input  wire rst_n,
  input  wire sel,
  output wire out_clk,
  output wire active_clock
);

  reg en_clk0_d1, en_clk0_d2;
  reg en_clk1_d1, en_clk1_d2;

  // Domain 0: Negative edge flops for clock 0 enable
  always @(negedge clk_0 or negedge rst_n) begin
    if (!rst_n) begin
      en_clk0_d1 <= 1'b1;
      en_clk0_d2 <= 1'b1;
    end else begin
      en_clk0_d1 <= (~sel) & (~en_clk1_d2);
      en_clk0_d2 <= en_clk0_d1;
    end
  end

  // Domain 1: Negative edge flops for clock 1 enable
  always @(negedge clk_1 or negedge rst_n) begin
    if (!rst_n) begin
      en_clk1_d1 <= 1'b0;
      en_clk1_d2 <= 1'b0;
    end else begin
      en_clk1_d1 <= sel & (~en_clk0_d2);
      en_clk1_d2 <= en_clk1_d1;
    end
  end

  // Glitch-free clock gating and OR recombination
  assign out_clk = (clk_0 & en_clk0_d2) | (clk_1 & en_clk1_d2);
  assign active_clock = en_clk1_d2;

endmodule

Architectural Deep Dive & Implementation Walkthrough
Why Pure Combinational Multiplexers Cause Clock Glitches


If you switch between two asynchronous clocks using a simple multiplexer (assign out_clk = sel ? clk_1 : clk_0;), switching when one clock is high and the other is low produces a momentary narrow pulse called a runt pulse.


Runt pulses violate setup and hold times of downstream flip-flops, causing chip-wide metastability and logic corruption.


The Glitch-Free Architecture Solution


    
  
  • Negative-Edge Sampling: Enabling or disabling a clock signal only when the clock is low ensures that rising edges are never truncated.
    • 
  
  • Cross-Feedback Handshaking: The target clock cannot turn on until the current clock has verified that its enable is 0.
    • 
  
  • Metastability Hardening: Dual flip-flops in each clock domain absorb any metastability from asynchronous sel changes.
    • 



      
Common RTL Designer Pitfalls
⚠️ Common Mistakes to Avoid
Triggering enable registers on posedge clk instead of negedge clk, which causes glitches during high phases.


      
Silicon & Hardware Engineering Notes
🛠️ ASIC vs FPGA Hardware Considerations
Standard cell libraries often provide specialized ICG (Integrated Clock Gating) cells with integrated negative-edge latches to save power and area.
