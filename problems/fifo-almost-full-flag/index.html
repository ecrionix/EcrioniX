Verified Synthesizable RTL 
module top_module #(
  parameter ALMOST_FULL_THRESHOLD = 12
)(
  input        clk,
  input        areset_n,
  input        wr_valid,
  input        rd_valid,
  output reg [4:0] occupancy,
  output       almost_full,
  output       full
);
  always @(posedge clk or negedge areset_n) begin
    if (!areset_n) begin
      occupancy <= 5'd0;
    end else begin
      case ({wr_valid, rd_valid})
        2'b10: occupancy <= occupancy + 1'b1;
        2'b01: occupancy <= occupancy - 1'b1;
        default: occupancy <= occupancy;
      endcase
    end
  end

  assign full        = (occupancy == 5'd16);
  assign almost_full = (occupancy >= ALMOST_FULL_THRESHOLD);
endmodule

Architectural Deep Dive & Implementation Walkthrough
In high-throughput interconnects (Ethernet MACs, PCIe controllers), stopping an upstream transmitter takes several clock cycles of round-trip pipeline latency. If flow control waited until the FIFO was 100% full before asserting backpressure, packets in flight would overflow and be dropped. The `almost_full` watermark signals backpressure with enough head-room margin (the skid depth) to safely absorb in-flight packets.

⚠️ Common Mistakes to Avoid

🛠️ ASIC vs FPGA Hardware Considerations
Configurable almost-full thresholds are standard features of hard FIFO macros in AMD/Xilinx UltraScale+ and Intel Agilex FPGAs.
