Hint 1: Conceptual Direction & Hardware Primitives
Gray code conversion is: gray = bin ^ (bin >> 1).
Hint 2: Implementation Architecture & Approach
To detect full, the write pointer has wrapped around while the read pointer has not. In Gray code, full condition occurs when the two most significant bits are inverted and all lower bits match.
Hint 3: Edge Cases, Timing & Verilog Syntax
Empty detection occurs in the read domain when rd_gray matches the synchronized wr_gray_s2 exactly.

module top_module #(
  parameter DATA_WIDTH = 8,
  parameter ADDR_WIDTH = 3 // Depth = 8
)(
  input  wire                  wr_clk,
  input  wire                  wr_rst_n,
  input  wire                  wr_en,
  input  wire [DATA_WIDTH-1:0] wr_data,
  input  wire                  rd_clk,
  input  wire                  rd_rst_n,
  input  wire                  rd_en,
  output wire [DATA_WIDTH-1:0] rd_data,
  output wire                  full,
  output wire                  empty
);

  localparam DEPTH = 1 << ADDR_WIDTH;

  reg [DATA_WIDTH-1:0] mem [0:DEPTH-1];

  // Binary and Gray pointers (ADDR_WIDTH+1 bits)
  reg [ADDR_WIDTH:0] wr_bin, wr_gray;
  reg [ADDR_WIDTH:0] rd_bin, rd_gray;

  // 2-Flop CDC synchronizers
  reg [ADDR_WIDTH:0] wr_gray_s1, wr_gray_s2; // into rd_clk domain
  reg [ADDR_WIDTH:0] rd_gray_s1, rd_gray_s2; // into wr_clk domain

  // Write operation
  wire write_valid = wr_en && !full;
  always @(posedge wr_clk) begin
    if (write_valid) begin
      mem[wr_bin[ADDR_WIDTH-1:0]] <= wr_data;
    end
  end

  always @(posedge wr_clk or negedge wr_rst_n) begin
    if (!wr_rst_n) begin
      wr_bin  <= 0;
      wr_gray <= 0;
    end else if (write_valid) begin
      wr_bin  <= wr_bin + 1'b1;
      wr_gray <= (wr_bin + 1'b1) ^ ((wr_bin + 1'b1) >> 1);
    end
  end

  // Synchronize rd_gray into wr_clk domain
  always @(posedge wr_clk or negedge wr_rst_n) begin
    if (!wr_rst_n) begin
      rd_gray_s1 <= 0;
      rd_gray_s2 <= 0;
    end else begin
      rd_gray_s1 <= rd_gray;
      rd_gray_s2 <= rd_gray_s1;
    end
  end

  // Full detection in wr_clk domain: MSB and 2nd MSB inverted, remaining bits equal
  assign full = (wr_gray == {~rd_gray_s2[ADDR_WIDTH:ADDR_WIDTH-1], rd_gray_s2[ADDR_WIDTH-2:0]});

  // Read operation
  wire read_valid = rd_en && !empty;
  assign rd_data = mem[rd_bin[ADDR_WIDTH-1:0]];

  always @(posedge rd_clk or negedge rd_rst_n) begin
    if (!rd_rst_n) begin
      rd_bin  <= 0;
      rd_gray <= 0;
    end else if (read_valid) begin
      rd_bin  <= rd_bin + 1'b1;
      rd_gray <= (rd_bin + 1'b1) ^ ((rd_bin + 1'b1) >> 1);
    end
  end

  // Synchronize wr_gray into rd_clk domain
  always @(posedge rd_clk or negedge rd_rst_n) begin
    if (!rd_rst_n) begin
      wr_gray_s1 <= 0;
      wr_gray_s2 <= 0;
    end else begin
      wr_gray_s1 <= wr_gray;
      wr_gray_s2 <= wr_gray_s1;
    end
  end

  // Empty detection in rd_clk domain
  assign empty = (rd_gray == wr_gray_s2);

endmodule

Architectural Deep Dive & Implementation Walkthrough
Classic Dual-Clock FIFO Architecture


Asynchronous FIFOs are ubiquitous in SoCs whenever data passes between independent oscillator domains (e.g. PCIe PHY, DDR controller, CPU core).


Why Gray Code is Mandatory


If binary pointers were synchronized across clock domains, a multi-bit change (e.g. 3'b011 -> 3'b100 where all 3 bits change simultaneously) would suffer from physical routing delay skew. The receiving synchronizer could sample intermediate corrupt codes (e.g. 3'b000 or 3'b111), causing false full or empty flags.


Gray code guarantees that exactly ONE bit changes between any two consecutive values ($000 	o 001 	o 011 	o 010$). Even if the synchronizer samples during a metastable transition, it can only ever resolve to either the old value or the new value, never an erroneous random code.


Synthesis Note: Real silicon implementations require the (* ASYNC_REG = "TRUE" *) attribute on synchronizer registers and a set_max_delay -datapath_only constraint in the SDC timing script.


      
Common RTL Designer Pitfalls
⚠️ Common Mistakes to Avoid
Checking full in the read clock domain or empty in the write clock domain. Full must be checked in wr_clk, empty in rd_clk.


      
Silicon & Hardware Engineering Notes
🛠️ ASIC vs FPGA Hardware Considerations
Async FIFO depth is restricted to powers of 2 ($2^N$) so that the Gray code sequence wraps around with a single-bit transition.
