CDC Bus Hold Register

Sequential Design · sequential, cdc, datapath

Capture a data bus only on a valid strobe and hold it steady otherwise — never let an unregistered async bus pass straight through to downstream logic.

Module Specification
Write a synthesizable Verilog module named top_module matching the ports below exactly.
Concept: A multi-bit bus crossing domains can't just be wired through combinationally — different bits can settle at slightly different times, so any glitch or skew on the source side becomes visible immediately downstream. The fix is to only ever update the output register when a (separately synchronized) valid strobe says the bus is stable: if (valid) data_out <= data_in;, holding the old value the rest of the time. Wiring data_out straight to data_in with no register at all defeats the entire point — every glitch on the input rides straight through.

Hardware Implementation & Synthesizable RTL Rules

      
A production-ready RTL implementation requires synthesizable design intent:

      
    
        
  • No Simulation Delays: Never include #delay statements inside synthesizable RTL modules.
    • 
        
  • Combinational vs Sequential Assignments: Use blocking assignments (=) only inside combinational always @(*) blocks; use non-blocking assignments (<=) exclusively inside edge-triggered always @(posedge clk) blocks.
    • 
        
  • Latch Avoidance: Ensure all outputs are assigned under every conditional branch (if/else and case) to prevent unintended latch inference.
