4-Bit Shift Register — Data Shifting

Sequential Logic · sequential, fsm, counters, medium, shift-registers

Implement a 4-bit serial-in parallel-out (SIPO) shift register. On each clock edge, data shifts left: q[3]<=q[2], q[2]<=q[1], q[1]<=q[0], q[0]<=din.

Use concatenation: `{q[2:0], din}` shifts all bits left by 1 and inserts `din` into the LSB (`q[0]`).

Write `q <= {q[2:0], din};`.

Verified Synthesizable RTL 
module top_module(
  input        clk,
  input        areset_n,
  input        din,
  output reg [3:0] q
);
  always @(posedge clk or negedge areset_n) begin
    if (!areset_n)
      q <= 4'b0000;
    else
      q <= {q[2:0], din};
  end
endmodule

Architectural Deep Dive & Implementation Walkthrough
A shift register connects the output of one flip-flop directly to the input of the next. On every clock tick, bits move along the pipeline chain. In SPI, UART, and I2C controllers, shift registers convert between bit-serial physical wires and byte-parallel processor registers.

Silicon & Hardware Engineering Notes
🛠️ ASIC vs FPGA Hardware Considerations
Modern FPGAs (AMD/Xilinx) can configure a single LUT as a 32-bit shift register (SRL32), implementing deep shift registers with zero flip-flop overhead.
