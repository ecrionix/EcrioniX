module top_module(
  input        clk,
  input        areset_n,
  output reg [3:0] q
);
  always @(posedge clk or negedge areset_n) begin
    if (!areset_n)
      q <= 4'd0;
    else if (q == 4'd9)
      q <= 4'd0;
    else
      q <= q + 1'b1;
  end
endmodule

Architectural Deep Dive & Implementation Walkthrough
A modulo-$M$ counter resets its state whenever it reaches terminal count $M-1$. In binary-coded decimal (BCD), cascading multiple decade counters creates multi-digit decimal displays (seconds, minutes, hours).


      
Common RTL Designer Pitfalls
⚠️ Common Mistakes to Avoid
['Checking `if (q == 10)`: this causes the counter to output 10 for one cycle before resetting, making it a modulo-11 counter.', 'Resetting asynchronously on the terminal count, causing severe glitching hazards.']


      
Silicon & Hardware Engineering Notes
🛠️ ASIC vs FPGA Hardware Considerations
Always perform terminal count reset synchronously (`if (q == 9) q <= 0;`). Asynchronous resets driven by combinational decode logic suffer from transient glitches and race conditions.
