Hint 2: Implementation Architecture & Approach

Verified Synthesizable RTL 
module top_module(
  input       clk,
  input       areset_n,
  input       in,
  output reg  p_edge
);
  reg in_d;
  always @(posedge clk or negedge areset_n) begin
    if (!areset_n) begin
      in_d   <= 1'b0;
      p_edge <= 1'b0;
    end else begin
      in_d   <= in;
      p_edge <= in & ~in_d;
    end
  end
endmodule

Architectural Deep Dive & Implementation Walkthrough
By registering the input signal, `in_d` holds the value of `in` from exactly one clock cycle in the past. Comparing the current value with the delayed value ($in \cdot \overline{in_d}$) evaluates to 1 exclusively during the single clock period when the signal transitioned from 0 to 1.
