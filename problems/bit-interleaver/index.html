Bit Interleaver (Morton-Style)

Combinational Design · combinational, bit-manipulation

Weave two 4-bit values together bit-by-bit into an 8-bit result — the core operation behind Morton (Z-order) codes used to turn 2D coordinates into a single cache-friendly index.

Module Specification
Write a synthesizable Verilog module named top_module matching the ports below exactly.
Concept: Interleaving alternates bits from each input starting from the top: out = {a[3],b[3],a[2],b[2],a[1],b[1],a[0],b[0]}, so every odd output bit position comes from a and every even position comes from b. Swapping which input feeds the odd vs. even slots is an easy mix-up when writing the concatenation by hand — the result is still a plausible-looking interleaved byte, it's just a and b completely swapped throughout.

Hardware Implementation & Synthesizable RTL Rules

      
A production-ready RTL implementation requires synthesizable design intent:

      
    
        
  • No Simulation Delays: Never include #delay statements inside synthesizable RTL modules.
    • 
        
  • Combinational vs Sequential Assignments: Use blocking assignments (=) only inside combinational always @(*) blocks; use non-blocking assignments (<=) exclusively inside edge-triggered always @(posedge clk) blocks.
    • 
        
  • Latch Avoidance: Ensure all outputs are assigned under every conditional branch (if/else and case) to prevent unintended latch inference.
