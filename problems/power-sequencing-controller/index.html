SoC Multi-Rail Power Sequencing Controller

Advanced RTL & Protocol Design · advanced-rtl, soc-controllers, systemverilog, asic, fpga

Design a deterministic hardware power-on and power-down sequencing controller with supply-good handshake monitoring and fault timeout protection.

Module Specification
Write a synthesizable Verilog module named top_module matching the ports below exactly.
📐 Circuit Schematic Diagram
⚡ Timing & Synthesizability Constraints

Timing Contract: Clocked on posedge clk with active-low async rst_n. Timeout limit = 15 cycles per state. Stabilization delay after clock enable = 4 cycles.

RTL Constraints: No rail order violation (IO must precede Core on power-up; Core must drop before IO on power-down). Synthesizable Verilog-2001.

Objective: Implement a multi-rail SoC power sequencer FSM. On pwr_req = 1, sequence voltage regulator enables (IO -> Core), monitor analog power-good flags, wait for PLL lock, enable clock gating, and deassert system reset after stabilization. Detect rail failure timeouts and execute an orderly shutdown.

Prerequisites: SoC power management, PMIC power sequencing, power-good handshaking, FSM design, watchdog timers.

Hint 1: Conceptual Direction & Hardware Primitives
Use a synchronous state machine with distinct states for power-up sequencing and reverse power-down collapse.
Hint 2: Implementation Architecture & Approach
Include a 4-bit timer that increments each cycle in wait states and resets upon state transitions.

Verified Synthesizable RTL 
module top_module (
  input  wire clk,
  input  wire rst_n,
  input  wire pwr_req,
  input  wire vdd_io_ok,
  input  wire vdd_core_ok,
  input  wire pll_locked,
  output reg  pwr_en_io,
  output reg  pwr_en_core,
  output reg  clk_enable,
  output reg  sys_rst_n_out,
  output reg  seq_error
);

  localparam S_IDLE        = 4'd0;
  localparam S_EN_IO       = 4'd1;
  localparam S_EN_CORE     = 4'd2;
  localparam S_WAIT_PLL    = 4'd3;
  localparam S_EN_CLK      = 4'd4;
  localparam S_ACTIVE      = 4'd5;
  localparam S_DOWN_RESET  = 4'd6;
  localparam S_DOWN_CLK    = 4'd7;
  localparam S_DOWN_CORE   = 4'd8;
  localparam S_DOWN_IO     = 4'd9;
  localparam S_ERROR       = 4'd10;

  reg [3:0] state, next_state;
  reg [3:0] timer;

  always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
      state <= S_IDLE;
      timer <= 4'd0;
    end else begin
      state <= next_state;
      if (state != next_state) begin
        timer <= 4'd0;
      end else begin
        timer <= timer + 4'd1;
      end
    end
  end

  always @(*) begin
    next_state = state;
    case (state)
      S_IDLE: begin
        if (pwr_req) next_state = S_EN_IO;
      end

      S_EN_IO: begin
        if (!pwr_req) next_state = S_DOWN_IO;
        else if (vdd_io_ok) next_state = S_EN_CORE;
        else if (timer >= 4'd15) next_state = S_ERROR;
      end

      S_EN_CORE: begin
        if (!pwr_req) next_state = S_DOWN_CORE;
        else if (vdd_core_ok) next_state = S_WAIT_PLL;
        else if (timer >= 4'd15) next_state = S_ERROR;
      end

      S_WAIT_PLL: begin
        if (!pwr_req) next_state = S_DOWN_CORE;
        else if (pll_locked) next_state = S_EN_CLK;
        else if (timer >= 4'd15) next_state = S_ERROR;
      end

      S_EN_CLK: begin
        if (!pwr_req) next_state = S_DOWN_CLK;
        else if (timer >= 4'd3) next_state = S_ACTIVE; // 4 stabilization cycles
      end

      S_ACTIVE: begin
        if (!pwr_req || !vdd_io_ok || !vdd_core_ok || !pll_locked) next_state = S_DOWN_RESET;
      end

      S_DOWN_RESET: next_state = S_DOWN_CLK;
      S_DOWN_CLK:   next_state = S_DOWN_CORE;
      S_DOWN_CORE:  next_state = S_DOWN_IO;
      S_DOWN_IO:    next_state = S_IDLE;

      S_ERROR: begin
        if (!pwr_req) next_state = S_IDLE;
      end

      default: next_state = S_IDLE;
    endcase
  end

  // Output registered decoding
  always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
      pwr_en_io     <= 1'b0;
      pwr_en_core   <= 1'b0;
      clk_enable    <= 1'b0;
      sys_rst_n_out <= 1'b0;
      seq_error     <= 1'b0;
    end else begin
      case (next_state)
        S_IDLE: begin
          pwr_en_io     <= 1'b0;
          pwr_en_core   <= 1'b0;
          clk_enable    <= 1'b0;
          sys_rst_n_out <= 1'b0;
        end
        S_EN_IO: begin
          pwr_en_io     <= 1'b1;
          pwr_en_core   <= 1'b0;
          clk_enable    <= 1'b0;
          sys_rst_n_out <= 1'b0;
        end
        S_EN_CORE: begin
          pwr_en_io     <= 1'b1;
          pwr_en_core   <= 1'b1;
          clk_enable    <= 1'b0;
          sys_rst_n_out <= 1'b0;
        end
        S_WAIT_PLL: begin
          pwr_en_io     <= 1'b1;
          pwr_en_core   <= 1'b1;
          clk_enable    <= 1'b0;
          sys_rst_n_out <= 1'b0;
        end
        S_EN_CLK: begin
          pwr_en_io     <= 1'b1;
          pwr_en_core   <= 1'b1;
          clk_enable    <= 1'b1;
          sys_rst_n_out <= 1'b0;
        end
        S_ACTIVE: begin
          pwr_en_io     <= 1'b1;
          pwr_en_core   <= 1'b1;
          clk_enable    <= 1'b1;
          sys_rst_n_out <= 1'b1;
        end
        S_DOWN_RESET: begin
          pwr_en_io     <= 1'b1;
          pwr_en_core   <= 1'b1;
          clk_enable    <= 1'b1;
          sys_rst_n_out <= 1'b0;
        end
        S_DOWN_CLK: begin
          pwr_en_io     <= 1'b1;
          pwr_en_core   <= 1'b1;
          clk_enable    <= 1'b0;
          sys_rst_n_out <= 1'b0;
        end
        S_DOWN_CORE: begin
          pwr_en_io     <= 1'b1;
          pwr_en_core   <= 1'b0;
          clk_enable    <= 1'b0;
          sys_rst_n_out <= 1'b0;
        end
        S_DOWN_IO: begin
          pwr_en_io     <= 1'b0;
          pwr_en_core   <= 1'b0;
          clk_enable    <= 1'b0;
          sys_rst_n_out <= 1'b0;
        end
        S_ERROR: begin
          pwr_en_io     <= 1'b0;
          pwr_en_core   <= 1'b0;
          clk_enable    <= 1'b0;
          sys_rst_n_out <= 1'b0;
          seq_error     <= 1'b1;
        end
      endcase
    end
  end

endmodule

Architectural Deep Dive & Implementation Walkthrough
Why Modern SoCs Require Strict Power Sequencing


Modern System-on-Chips contain distinct power domains: I/O pads (1.8V/3.3V), analog PLLs (1.2V), and digital logic cores (0.75V - 0.9V). Violating the turn-on order can cause forward-biasing of parasitic PN junctions, leading to destructive CMOS latch-up.


Typical SoC Power-Up Sequence


    
  
  1. I/O Power First: Turn on I/O rails so pads enter safe tri-state mode without driving floating voltages onto unpowered external interfaces.
    2. 
  
  2. Core Power Second: Ramp the internal digital core voltage. Wait for external PMIC power_good assertion.
    3. 
  
  3. Analog Lock: Enable analog PLLs and wait for lock status.
    4. 
  
  4. Clock Distribution: Ungate internal clock trees, allowing flip-flops to stabilize under valid clock edges.
    5. 
  
  5. Reset Release: Deassert synchronous reset cleanly aligned to clock edges.
    6. 



      
Common RTL Designer Pitfalls
⚠️ Common Mistakes to Avoid
Deasserting reset before clocks stabilize, or shutting down I/O rails before the core logic has ceased activity.


      
Silicon & Hardware Engineering Notes
🛠️ ASIC vs FPGA Hardware Considerations
Silicon power sequencers are placed in an "Always-On" (AON) power domain powered by an auxiliary backup battery or low-dropout regulator (LDO).
