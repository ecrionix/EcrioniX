SPI Full-Duplex Shift Register

Sequential Design · sequential, protocol

Build the core shift register behind SPI: transmit a byte MSB-first while simultaneously receiving one, both directions moving on the same clock edge.

Module Specification
Write a synthesizable Verilog module named top_module matching the ports below exactly.
📐 Circuit Schematic Diagram
⚡ Timing & Synthesizability Constraints

Timing Contract: Strict synchronous timing aligned to posedge clk or zero-delay combinational propagation.

RTL Constraints: Synthesizable Verilog-2001. No # delays in synthesizable RTL.

Concept: SPI's shift register does two things on every clock edge at once: the top bit shifts out on miso, and a new bit shifts in from mosi at the bottom — shreg <= {shreg[6:0], mosi}, with miso reading shreg[7] combinationally. A load pulse parallel-loads a fresh byte to transmit. Shifting the wrong direction ({mosi, shreg[7:1]}) swaps which end transmits first and which end receives — a mirror-image bug that still compiles and still shifts, just not the way SPI actually works.

Problem Statement & Requirements

      
Build the core shift register behind SPI: transmit a byte MSB-first while simultaneously receiving one, both directions moving on the same clock edge.

      
Hardware design teams at leading semiconductor firms evaluate these exact port contracts, race-condition assertions, and corner cases during technical design reviews and ASIC engineer interviews.

      
      
Concept: SPI's shift register does two things on every clock edge at once: the top bit shifts out on miso, and a new bit shifts in from mosi at the bottom — shreg <= {shreg[6:0], mosi}, with miso reading shreg[7] combinationally. A load pulse parallel-loads a fresh byte to transmit. Shifting the wrong direction ({mosi, shreg[7:1]}) swaps which end transmits first and which end receives — a mirror-image bug that still compiles and still shifts, just not the way SPI actually works.
