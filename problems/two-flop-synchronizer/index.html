module top_module(
  input   clk_dst,
  input   areset_n,
  input   async_in,
  output  sync_out
);
  (* ASYNC_REG = "TRUE" *) reg q1;
  (* ASYNC_REG = "TRUE" *) reg q2;

  always @(posedge clk_dst or negedge areset_n) begin
    if (!areset_n) begin
      q1 <= 1'b0;
      q2 <= 1'b0;
    end else begin
      q1 <= async_in;
      q2 <= q1;
    end
  end

  assign sync_out = q2;
endmodule

Synthesis Constraints: Never apply 2-flop synchronizers to multi-bit buses without Gray coding or handshakes. Synthesizable sequential RTL.

        

      


      
Architectural Deep Dive & Implementation Walkthrough
When an asynchronous signal transitions near a clock edge, the first flip-flop (FF1) can enter a metastable state where its output voltage hovers between valid logic levels. The second flip-flop (FF2) provides an entire clock period of settling time for FF1 to resolve to a stable 0 or 1, exponentially increasing the Mean Time Between Failures (MTBF).


      
Common RTL Designer Pitfalls
⚠️ Common Mistakes to Avoid

Silicon & Hardware Engineering Notes
🛠️ ASIC vs FPGA Hardware Considerations
CRITICAL CDC NOTE: Passing functional simulation does not prove CDC safety! Static CDC verification tools (Synopsys SpyGlass CDC, Questa CDC) and physical placement constraints (`set_false_path`, `set_max_delay -datapath_only`) are mandatory in silicon design.
